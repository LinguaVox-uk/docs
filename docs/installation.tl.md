# Pag-install ng LinguaVox

## Opsyon A — Chrome Web Store (Inirerekomenda)

1. Buksan ang [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. I-click ang **Idagdag sa Chrome**
3. I-click ang LinguaVox icon sa Chrome toolbar
4. I-click ang **Mag-sign in gamit ang Google**
5. I-click ang anumang text field sa anumang website, hawakan ang **Ctrl+Space**, at magsalita ✓

## Opsyon B — Manual na Pag-install (ZIP)

1. I-download ang `linguavox-3.0.0.zip` mula sa [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. I-unzip sa isang folder sa iyong computer
3. Buksan ang Chrome → pumunta sa `chrome://extensions`
4. I-enable ang **Developer mode** (toggle sa kanang sulok sa itaas)
5. I-click ang **Load unpacked** → piliin ang na-unzip na folder

## Unang Paggamit

Pagkatapos mag-install:
- I-click ang LinguaVox icon → mag-sign in gamit ang Google (isang click, walang password)
- I-click ang anumang text field sa anumang website
- Hawakan ang **Ctrl+Space** (Windows/Linux) o **Alt+Shift+Q** (Mac) at magsalita
- Pakawalan — lalabas ang teksto sa loob ng 3 segundo

## Pag-uninstall

Chrome toolbar → i-right-click ang LinguaVox icon → **Alisin mula sa Chrome**
