# LinguaVox — 设置指南

点击 Chrome 工具栏中的图标，打开 LinguaVox 弹出窗口。

---

## 语音语言

您将使用的说话语言。设置为**自动**让 LinguaVox 自动检测，或选择特定语言以获得更好的口音或方言识别精度。

---

## 模式

| 模式 | 功能 |
|------|------|
| **转录** | 将您的语音精确转换为文字 |
| **翻译** | 将您的语音转换为另一种语言 |
| **增强** | 转录并自动应用 AI 润色 |

---

## 输出语言（翻译模式）

当模式设置为**翻译**时，选择您希望最终文本使用的语言。

示例：
- 说中文 → 输出：Gmail 中的专业英语
- 说西班牙语 → 输出：Slack 中的德语
- 说任何语言 → 输出：21+ 种语言中的任意一种

---

## AI 增强

自动改进转录文本。选择适合您使用场景的风格：

| 风格 | 最适合 |
|------|--------|
| **智能润色** | 日常使用——修正语法，保留含义 |
| **商务风格** | 邮件、报告、专业消息 |
| **仅语法** | 语法和拼写修正，不改写 |
| **创意** | 社交帖子、故事讲述、创意写作 |
| **休闲** | 聊天消息、非正式对话 |
| **学术** | 论文、研究、正式文件 |

增强可以关闭——仅运行 Whisper 转录。

---

## 会议模式

为任何视频通话（Google Meet、Zoom、Teams 等）添加实时翻译字幕。通过右键点击 LinguaVox 图标启动。开始前选择字幕语言。

---

## 界面语言

更改 LinguaVox 弹出窗口本身的语言。支持 14 种语言。不影响转录或输出。

---

## 夜间模式

将弹出窗口切换为深色主题。

---

## 历史记录

最近的转录内容本地保存在您的浏览器中。设置保存数量（10、25、50 或 100）。历史记录是私密的——仅存储在您的设备上，绝不上传到我们的服务器。

---

## API 密钥

默认情况下，LinguaVox 使用共享密钥池（每天 20 次免费请求）。添加您自己的 OpenAI API 密钥以获得无限请求。您的密钥安全存储在浏览器中，仅用于您自己的转录。

要添加密钥：打开[控制面板 → API Key](https://linguavox.uk/login)
