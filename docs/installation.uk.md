# Встановлення LinguaVox

## Варіант A — Chrome Web Store (Рекомендовано)

1. Відкрийте [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Натисніть **Додати до Chrome**
3. Натисніть на іконку LinguaVox на панелі Chrome
4. Натисніть **Увійти через Google**
5. Клацніть будь-яке текстове поле на будь-якому сайті, утримуйте **Ctrl+Space** і говоріть ✓

## Варіант B — Ручне встановлення (ZIP)

1. Завантажте `linguavox-3.0.0.zip` з [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Розпакуйте у папку на вашому комп'ютері
3. Відкрийте Chrome → перейдіть на `chrome://extensions`
4. Увімкніть **Режим розробника** (перемикач у верхньому правому куті)
5. Натисніть **Завантажити розпаковане** → оберіть розпаковану папку

## Перше використання

Після встановлення:
- Натисніть на іконку LinguaVox → увійдіть через Google (один клік, без пароля)
- Клацніть будь-яке текстове поле на будь-якому сайті
- Утримуйте **Ctrl+Space** (Windows/Linux) або **Alt+Shift+Q** (Mac) і говоріть
- Відпустіть — текст з'явиться менш ніж за 3 секунди

## Видалення

Панель Chrome → клацніть правою кнопкою на іконку LinguaVox → **Видалити з Chrome**
