# LinguaVox ਇੰਸਟਾਲ ਕਰਨਾ

## ਵਿਕਲਪ A — Chrome Web Store (ਸਿਫਾਰਿਸ਼ ਕੀਤਾ)

1. [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea) ਖੋਲ੍ਹੋ
2. **Chrome ਵਿੱਚ ਸ਼ਾਮਲ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ
3. Chrome toolbar ਵਿੱਚ LinguaVox ਆਈਕਨ ਤੇ ਕਲਿੱਕ ਕਰੋ
4. **Google ਨਾਲ ਸਾਈਨ ਇਨ ਕਰੋ** ਤੇ ਕਲਿੱਕ ਕਰੋ
5. ਕਿਸੇ ਵੀ ਵੈੱਬਸਾਈਟ ਤੇ ਟੈਕਸਟ ਫੀਲਡ ਵਿੱਚ ਕਲਿੱਕ ਕਰੋ, **Ctrl+Space** ਦਬਾ ਕੇ ਰੱਖੋ ਅਤੇ ਬੋਲੋ ✓

## ਵਿਕਲਪ B — ਦਸਤੀ ਇੰਸਟਾਲੇਸ਼ਨ (ZIP)

1. [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest) ਤੋਂ `linguavox-3.0.0.zip` ਡਾਊਨਲੋਡ ਕਰੋ
2. ਆਪਣੇ ਕੰਪਿਊਟਰ ਤੇ ਇੱਕ ਫੋਲਡਰ ਵਿੱਚ ਅਨਜ਼ਿੱਪ ਕਰੋ
3. Chrome ਖੋਲ੍ਹੋ → `chrome://extensions` ਤੇ ਜਾਓ
4. **Developer mode** ਸਮਰੱਥ ਕਰੋ (ਉੱਪਰ ਸੱਜੇ ਕੋਨੇ ਵਿੱਚ ਟੌਗਲ)
5. **Load unpacked** ਤੇ ਕਲਿੱਕ ਕਰੋ → ਅਨਜ਼ਿੱਪ ਕੀਤਾ ਫੋਲਡਰ ਚੁਣੋ

## ਪਹਿਲੀ ਵਰਤੋਂ

ਇੰਸਟਾਲ ਕਰਨ ਤੋਂ ਬਾਅਦ:
- LinguaVox ਆਈਕਨ ਤੇ ਕਲਿੱਕ ਕਰੋ → Google ਨਾਲ ਸਾਈਨ ਇਨ ਕਰੋ (ਇੱਕ ਕਲਿੱਕ, ਕੋਈ ਪਾਸਵਰਡ ਨਹੀਂ)
- ਕਿਸੇ ਵੀ ਵੈੱਬਸਾਈਟ ਤੇ ਟੈਕਸਟ ਫੀਲਡ ਵਿੱਚ ਕਲਿੱਕ ਕਰੋ
- **Ctrl+Space** (Windows/Linux) ਜਾਂ **Alt+Shift+Q** (Mac) ਦਬਾ ਕੇ ਰੱਖੋ ਅਤੇ ਬੋਲੋ
- ਛੱਡੋ — ਟੈਕਸਟ 3 ਸਕਿੰਟ ਤੋਂ ਘੱਟ ਵਿੱਚ ਦਿਖਾਈ ਦਿੰਦਾ ਹੈ

## ਅਣਇੰਸਟਾਲ ਕਰਨਾ

Chrome toolbar → LinguaVox ਆਈਕਨ ਤੇ ਸੱਜਾ ਕਲਿੱਕ ਕਰੋ → **Chrome ਤੋਂ ਹਟਾਓ**
