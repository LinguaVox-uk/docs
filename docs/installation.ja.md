# LinguaVox のインストール

## オプション A — Chrome Web Store（推奨）

1. [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea) を開く
2. **Chrome に追加**をクリック
3. Chrome ツールバーの LinguaVox アイコンをクリック
4. **Google でサインイン**をクリック
5. 任意のウェブサイトのテキストフィールドをクリックし、**Ctrl+Space** を押しながら話す ✓

## オプション B — 手動インストール（ZIP）

1. [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest) から `linguavox-3.0.0.zip` をダウンロード
2. コンピューターのフォルダに解凍
3. Chrome を開く → `chrome://extensions` に移動
4. **デベロッパーモード**を有効化（右上のトグル）
5. **パッケージ化されていない拡張機能を読み込む**をクリック → 解凍したフォルダを選択

## 初回使用

インストール後：
- LinguaVox アイコンをクリック → Google でサインイン（ワンクリック、パスワード不要）
- 任意のウェブサイトのテキストフィールドをクリック
- **Ctrl+Space**（Windows/Linux）または **Alt+Shift+Q**（Mac）を押しながら話す
- 離す — 3秒以内にテキストが表示される

## アンインストール

Chrome ツールバー → LinguaVox アイコンを右クリック → **Chrome から削除**
