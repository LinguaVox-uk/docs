# LinguaVox — Οδηγός ρυθμίσεων

Ανοίξτε το αναδυόμενο παράθυρο LinguaVox κάνοντας κλικ στο εικονίδιο στη γραμμή εργαλείων Chrome.

---

## Γλώσσα ομιλίας

Η γλώσσα που θα μιλήσετε. Ορίστε σε **Αυτόματο** για αυτόματη ανίχνευση, ή επιλέξτε συγκεκριμένη γλώσσα για καλύτερη ακρίβεια με τοπικές προφορές ή διαλέκτους.

---

## Λειτουργία

| Λειτουργία | Τι κάνει |
|-----------|---------|
| **Μεταγραφή** | Μετατρέπει την ομιλία σε κείμενο ακριβώς όπως ειπώθηκε |
| **Μετάφραση** | Μετατρέπει την ομιλία σε διαφορετική γλώσσα |
| **Βελτίωση** | Μεταγράφει και εφαρμόζει αυτόματα στίλβωση ΤΝ |

---

## Γλώσσα εξόδου (λειτουργία μετάφρασης)

Όταν η λειτουργία είναι **Μετάφραση**, επιλέξτε τη γλώσσα για το τελικό κείμενο.

Παραδείγματα:
- Μιλήστε ουκρανικά → έξοδος: επαγγελματικά αγγλικά στο Gmail
- Μιλήστε ισπανικά → έξοδος: γερμανικά στο Slack
- Μιλήστε οποιαδήποτε γλώσσα → έξοδος: οποιαδήποτε από 21+ γλώσσες

---

## Βελτίωση ΤΝ

Βελτιώνει αυτόματα το μεταγραμμένο κείμενο. Επιλέξτε ύφος που ταιριάζει στη χρήση σας:

| Ύφος | Ιδανικό για |
|------|-----------|
| **Έξυπνη στίλβωση** | Καθημερινή χρήση — διόρθωση γραμματικής, διατήρηση νοήματος |
| **Επαγγελματικό ύφος** | Email, αναφορές, επαγγελματικά μηνύματα |
| **Μόνο γραμματική** | Διόρθωση γραμματικής και ορθογραφίας χωρίς αναδιατύπωση |
| **Δημιουργικό** | Αναρτήσεις στα μέσα κοινωνικής δικτύωσης, αφήγηση, δημιουργική γραφή |
| **Ανεπίσημο** | Μηνύματα chat, ανεπίσημη συνομιλία |
| **Ακαδημαϊκό** | Δοκίμια, έρευνα, επίσημα έγγραφα |

Η βελτίωση μπορεί να απενεργοποιηθεί — θα εκτελείται μόνο η μεταγραφή Whisper.

---

## Λειτουργία Σύσκεψης

Προσθέτει μεταφρασμένους υπότιτλους σε πραγματικό χρόνο σε οποιαδήποτε βιντεοκλήση (Google Meet, Zoom, Teams κ.ά.). Ξεκινήστε με δεξί κλικ στο εικονίδιο LinguaVox. Επιλέξτε τη γλώσσα των υποτίτλων πριν ξεκινήσετε.

---

## Γλώσσα διεπαφής

Αλλάζει τη γλώσσα του αναδυόμενου παραθύρου LinguaVox. Υποστηρίζει 14 γλώσσες. Δεν επηρεάζει τη μεταγραφή ή την έξοδο.

---

## Νυχτερινή λειτουργία

Αλλάζει το αναδυόμενο παράθυρο σε σκούρο θέμα.

---

## Ιστορικό

Πρόσφατες μεταγραφές αποθηκεύονται τοπικά στο πρόγραμμα περιήγησης. Ορίστε πόσες να διατηρηθούν (10, 25, 50 ή 100). Το ιστορικό είναι ιδιωτικό — αποθηκεύεται μόνο στη συσκευή σας, ποτέ στους διακομιστές μας.

---

## Κλειδί API

Από προεπιλογή, η LinguaVox χρησιμοποιεί κοινόχρηστο σύνολο κλειδιών (20 αιτήματα/ημέρα δωρεάν). Προσθέστε το δικό σας κλειδί API OpenAI για απεριόριστα αιτήματα. Το κλειδί σας αποθηκεύεται ασφαλώς στο πρόγραμμα περιήγησης και χρησιμοποιείται μόνο για τις δικές σας μεταγραφές.

Για να προσθέσετε το κλειδί σας: ανοίξτε [Πίνακας ελέγχου → API Key](https://linguavox.uk/login)
