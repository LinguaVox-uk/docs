# LinguaVox — 자주 묻는 질문

## 시작하기

**OpenAI API 키가 필요한가요?**  
아니요. 무료 사용자는 설정 없이 하루 20회 요청을 받습니다. 무제한 사용을 위해 대시보드에서 자신의 키를 추가하세요.

**녹음을 시작하는 방법은?**  
**Ctrl+Space** (Windows/Linux) 또는 **Alt+Shift+Q** (Mac)를 누른 채로 말하고 놓으세요. 텍스트가 3초 내에 활성 필드에 나타납니다.

**어디서 로그인하나요?**  
Chrome 도구 모음의 LinguaVox 아이콘 → "Google로 로그인"을 클릭하세요. 클릭 한 번, 비밀번호 없음.

**어떤 웹사이트에서 작동하나요?**  
텍스트 필드가 있는 모든 웹사이트: Gmail, Slack, Notion, Jira, Salesforce, WhatsApp Web, Telegram Web, LinkedIn 등.

## 언어와 정확도

**지원되는 언어는?**  
21개 이상의 언어: 영어, 우크라이나어, 러시아어, 중국어, 스페인어, 독일어, 일본어, 프랑스어, 한국어, 아랍어, 포르투갈어, 이탈리아어, 폴란드어, 네덜란드어, 터키어, 스웨덴어, 루마니아어, 그리스어, 필리핀어, 우르두어, 펀자브어 등.

**정확도는 어떤가요?**  
OpenAI Whisper를 사용하여 단어 수준 정확도 95% 이상. AI 향상 모드가 나머지 오류를 자동으로 수정할 수 있습니다.

**한 언어로 말하고 다른 언어로 출력받을 수 있나요?**  
네. 모드를 **번역**으로 설정하고 대상 언어를 선택하세요. 무엇이든 말하면 번역되어 전송 준비된 상태로 도착합니다.

## 개인정보

**내 목소리가 저장되나요?**  
아니요. 오디오는 실시간으로 처리되고 전사 후 즉시 삭제됩니다. 음성 녹음은 전혀 저장되지 않습니다.

**LinguaVox가 내 화면이나 브라우저 기록을 읽나요?**  
아니요. 핫키를 누르고 있을 때만 활성화됩니다. 다른 탭이나 브라우저 기록에 접근할 수 없습니다.

---

## 한도 및 가격

**무료 플랜에는 무엇이 포함되나요?**  
하루 20회 요청. 자정에 초기화. 신용카드 불필요.

**무제한 요청은 어떻게 얻나요?**  
대시보드 → API Key에서 자신의 OpenAI API 키를 추가하세요. OpenAI에 직접 결제 — 일반적인 비용은 월 $0.50 미만.

**조직 계정이란?**  
하나의 API 키가 팀 전체를 커버하는 공유 플랜. 대시보드에서 멤버를 관리하고 사용 분석을 확인하세요.

---

## 회의 모드

**회의 모드란?**  
Google Meet, Zoom, Teams 및 브라우저 기반 화상 통화를 위한 실시간 번역 자막. 자막이 화면의 플로팅 오버레이로 나타납니다.

**회의 모드를 시작하는 방법은?**  
Chrome 도구 모음의 LinguaVox 아이콘을 우클릭 → "회의 모드 시작." 활성 탭에서 작동합니다.

**회의 모드가 macOS에서 작동하나요?**  
네. 하지만 macOS는 브라우저에 화면 녹화 권한이 필요합니다. Chrome이 처음 사용 시 묻습니다.

---

## 문제 해결

**말한 후 텍스트가 나타나지 않았습니다.**  
먼저 텍스트 필드 안을 클릭한 다음 핫키를 누르세요. LinguaVox 아이콘이 로그인 상태를 표시하는지 확인하세요.

**이 사이트에서 핫키가 작동하지 않습니다.**  
LinguaVox는 페이지 수준 캡처(Slack 등)를 우회하는 브라우저 수준 핫키를 사용합니다. 여전히 작동하지 않으면 페이지를 새로고침하세요.

**일일 한도에 도달했습니다.**  
자정까지 기다리거나(한도가 매일 초기화) 무제한 사용을 위해 자신의 OpenAI API 키를 추가하세요.

**확장 프로그램에 "context invalidated"가 표시됩니다.**  
페이지를 새로고침하세요. 복잡한 단일 페이지 앱에서 탐색 후 발생할 수 있습니다.
