# LinguaVox — 常见问题

## 入门

**我需要 OpenAI API 密钥吗？**  
不需要。免费用户每天可获得 20 次请求，无需任何配置。在控制面板中添加您自己的密钥即可无限使用。

**如何开始录音？**  
按住 **Ctrl+Space**（Windows/Linux）或 **Alt+Shift+Q**（Mac），说话，然后松开。文字将在 3 秒内出现在活动输入框中。

**在哪里登录？**  
点击 Chrome 工具栏中的 LinguaVox 图标 → "使用 Google 登录"。一键登录，无需密码。

**适用于哪些网站？**  
任何有文本输入框的网站：Gmail、Slack、Notion、Jira、Salesforce、WhatsApp Web、Telegram Web、LinkedIn 等。

---

## 语言与准确性

**支持哪些语言？**  
21+ 种语言：英语、乌克兰语、俄语、中文、西班牙语、德语、日语、法语、韩语、阿拉伯语、葡萄牙语、意大利语、波兰语、荷兰语、土耳其语、瑞典语、罗马尼亚语、希腊语、菲律宾语、乌尔都语、旁遮普语等。

**准确率如何？**  
基于 OpenAI Whisper，词级准确率达 95%+。AI 增强模式可自动修正剩余错误。

**可以用一种语言说话，输出另一种语言吗？**  
可以。将模式设置为**翻译**，选择目标语言。说任何内容——输出将以翻译后的形式准备好发送。

---

## 隐私

**我的声音会被存储吗？**  
不会。音频实时处理，转录后立即删除。零语音录音存储。

**LinguaVox 会读取我的屏幕或浏览历史吗？**  
不会。仅在您按住热键时激活。无法访问其他标签页或您的浏览历史。

---

## 限制与定价

**免费套餐包含什么？**  
每天 20 次请求。午夜重置。无需信用卡。

**如何获得无限请求？**  
在控制面板 → API Key 中添加您自己的 OpenAI API 密钥。直接向 OpenAI 付费——日常使用的典型费用不到每月 $0.50。

**什么是企业账户？**  
共享方案，一个 API 密钥覆盖整个团队。在控制面板中管理成员并查看使用分析。

---

## 会议模式

**什么是会议模式？**  
为 Google Meet、Zoom、Teams 及任何基于浏览器的视频通话提供实时翻译字幕。字幕以浮动叠加层形式显示在屏幕上。

**如何启动会议模式？**  
右键点击 Chrome 工具栏中的 LinguaVox 图标 → "启动会议模式"。适用于当前标签页。

**会议模式在 macOS 上可以使用吗？**  
可以，但 macOS 需要为浏览器授予屏幕录制权限。Chrome 在首次使用时会提示您。

---

## 故障排除

**说话后文字没有出现。**  
先点击文本输入框内部，然后按住热键。确保 LinguaVox 图标显示您已登录。

**热键在此网站上不起作用。**  
LinguaVox 使用浏览器级热键，绕过页面级捕获（如 Slack）。如果仍然不起作用，请刷新页面。

**我已用完每日限额。**  
等到午夜（限额每日重置）或添加您自己的 OpenAI API 密钥以无限使用。

**扩展显示"context invalidated"。**  
刷新页面。这可能在导航后的复杂单页应用中发生。
