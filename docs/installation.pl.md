# Instalacja LinguaVox

## Opcja A — Chrome Web Store (Zalecane)

1. Otwórz [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Kliknij **Dodaj do Chrome**
3. Kliknij ikonę LinguaVox na pasku Chrome
4. Kliknij **Zaloguj się przez Google**
5. Kliknij dowolne pole tekstowe na dowolnej stronie, przytrzymaj **Ctrl+Space** i mów ✓

## Opcja B — Instalacja ręczna (ZIP)

1. Pobierz `linguavox-3.0.0.zip` z [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Rozpakuj do folderu na komputerze
3. Otwórz Chrome → przejdź do `chrome://extensions`
4. Włącz **Tryb dewelopera** (przełącznik w prawym górnym rogu)
5. Kliknij **Załaduj rozpakowane** → wybierz rozpakowany folder

## Pierwsze użycie

Po instalacji:
- Kliknij ikonę LinguaVox → zaloguj się przez Google (jeden klik, bez hasła)
- Kliknij dowolne pole tekstowe na dowolnej stronie
- Przytrzymaj **Ctrl+Space** (Windows/Linux) lub **Alt+Shift+Q** (Mac) i mów
- Puść — tekst pojawia się w ciągu 3 sekund

## Odinstalowanie

Pasek Chrome → kliknij prawym przyciskiem myszy ikonę LinguaVox → **Usuń z Chrome**
