# Installing LinguaVox

## Option A — Chrome Web Store (Recommended)

1. Open [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Click **Add to Chrome**
3. Click the LinguaVox icon in the Chrome toolbar
4. Click **Sign in with Google**
5. Click any text field on any website, hold **Ctrl+Space**, and speak ✓

## Option B — Manual Install (ZIP)

1. Download `linguavox-3.0.0.zip` from [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Unzip to a folder on your computer
3. Open Chrome → go to `chrome://extensions`
4. Enable **Developer mode** (toggle in the top-right corner)
5. Click **Load unpacked** → select the unzipped folder

## First Use

After installing:
- Click the LinguaVox icon → sign in with Google (one click, no password)
- Click any text field on any website
- Hold **Ctrl+Space** (Windows/Linux) or **Alt+Shift+Q** (Mac) and speak
- Release — text appears in under 3 seconds

## Uninstall

Chrome toolbar → right-click the LinguaVox icon → **Remove from Chrome**
