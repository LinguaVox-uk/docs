# LinguaVox installeren

## Optie A — Chrome Web Store (Aanbevolen)

1. Open de [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Klik op **Toevoegen aan Chrome**
3. Klik op het LinguaVox-pictogram in de Chrome-werkbalk
4. Klik op **Inloggen met Google**
5. Klik op een tekstveld op een willekeurige website, houd **Ctrl+Space** ingedrukt en spreek ✓

## Optie B — Handmatige installatie (ZIP)

1. Download `linguavox-3.0.0.zip` van [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Pak uit in een map op je computer
3. Open Chrome → ga naar `chrome://extensions`
4. Schakel de **Ontwikkelaarsmodus** in (schakelaar rechts bovenaan)
5. Klik op **Uitgepakte extensie laden** → selecteer de uitgepakte map

## Eerste gebruik

Na de installatie:
- Klik op het LinguaVox-pictogram → inloggen met Google (één klik, geen wachtwoord)
- Klik op een tekstveld op een willekeurige website
- Houd **Ctrl+Space** (Windows/Linux) of **Alt+Shift+Q** (Mac) ingedrukt en spreek
- Laat los — tekst verschijnt binnen 3 seconden

## Verwijderen

Chrome-werkbalk → rechts klikken op het LinguaVox-pictogram → **Verwijderen uit Chrome**
