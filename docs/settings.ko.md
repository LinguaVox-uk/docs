# LinguaVox — 설정 가이드

Chrome 도구 모음의 아이콘을 클릭하여 LinguaVox 팝업을 열어주세요.

---

## 음성 언어

말할 언어입니다. LinguaVox가 자동으로 감지하도록 **자동**으로 설정하거나, 억양이나 방언에 대한 더 나은 정확도를 위해 특정 언어를 선택하세요.

---

## 모드

| 모드 | 기능 |
|------|------|
| **전사** | 말한 그대로 음성을 텍스트로 변환 |
| **번역** | 음성을 다른 언어로 변환 |
| **향상** | 전사하고 자동으로 AI 다듬기 적용 |

---

## 출력 언어 (번역 모드)

모드가 **번역**으로 설정되면 최종 텍스트에 사용할 언어를 선택하세요.

예시:
- 우크라이나어로 말하기 → 출력: Gmail의 전문적인 영어
- 스페인어로 말하기 → 출력: Slack의 독일어
- 어떤 언어로든 말하기 → 출력: 21개 이상의 언어 중 하나

---

## AI 향상

전사된 텍스트를 자동으로 개선합니다. 사용 사례에 맞는 스타일을 선택하세요:

| 스타일 | 최적 용도 |
|--------|---------|
| **스마트 다듬기** | 일상 사용 — 문법 수정, 의미 보존 |
| **비즈니스 스타일** | 이메일, 보고서, 전문적인 메시지 |
| **문법만** | 문법 및 맞춤법 수정, 재구성 없음 |
| **창의적** | SNS 게시물, 스토리텔링, 창작 글쓰기 |
| **캐주얼** | 채팅 메시지, 비공식 대화 |
| **학술적** | 에세이, 연구, 공식 문서 |

향상을 끌 수 있습니다 — Whisper 전사만 실행됩니다.

---

## 회의 모드

모든 화상 통화(Google Meet, Zoom, Teams 등)에 실시간 번역 자막을 추가합니다. LinguaVox 아이콘 우클릭으로 시작합니다. 시작 전에 자막 언어를 선택하세요.

---

## 인터페이스 언어

LinguaVox 팝업 자체의 언어를 변경합니다. 14개 언어를 지원합니다. 전사나 출력에는 영향을 주지 않습니다.

---

## 야간 모드

팝업을 다크 테마로 전환합니다.

---

## 기록

최근 전사 내용이 브라우저에 로컬로 저장됩니다. 보관할 수를 설정하세요 (10, 25, 50, 또는 100). 기록은 비공개입니다 — 기기에만 저장되고, 서버에는 절대 저장되지 않습니다.

---

## API 키

기본적으로 LinguaVox는 공유 키 풀을 사용합니다 (하루 20회 무료). 무제한 요청을 위해 자신의 OpenAI API 키를 추가하세요. 키는 브라우저에 안전하게 저장되고 본인의 전사에만 사용됩니다.

키를 추가하려면: [대시보드 → API Key](https://linguavox.uk/login) 열기
