# LinguaVox 설치

## 옵션 A — Chrome 웹 스토어 (권장)

1. [Chrome 웹 스토어 →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea) 열기
2. **Chrome에 추가** 클릭
3. Chrome 도구 모음의 LinguaVox 아이콘 클릭
4. **Google로 로그인** 클릭
5. 아무 웹사이트의 텍스트 필드를 클릭하고 **Ctrl+Space**를 누른 채 말하기 ✓

## 옵션 B — 수동 설치 (ZIP)

1. [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)에서 `linguavox-3.0.0.zip` 다운로드
2. 컴퓨터의 폴더에 압축 해제
3. Chrome 열기 → `chrome://extensions`로 이동
4. **개발자 모드** 활성화 (오른쪽 상단 토글)
5. **압축 해제된 확장 프로그램 로드** 클릭 → 압축 해제된 폴더 선택

## 첫 사용

설치 후:
- LinguaVox 아이콘 클릭 → Google로 로그인 (클릭 한 번, 비밀번호 없음)
- 아무 웹사이트의 텍스트 필드 클릭
- **Ctrl+Space** (Windows/Linux) 또는 **Alt+Shift+Q** (Mac)를 누른 채 말하기
- 놓으면 — 3초 내에 텍스트 나타남

## 제거

Chrome 도구 모음 → LinguaVox 아이콘 우클릭 → **Chrome에서 삭제**
