# LinguaVox — اکثر پوچھے جانے والے سوالات

## شروعات

**کیا مجھے OpenAI API key کی ضرورت ہے؟**  
نہیں۔ مفت صارفین بغیر کسی ترتیب کے روزانہ 20 درخواستیں حاصل کرتے ہیں۔ لامحدود استعمال کے لیے ڈیش بورڈ میں اپنی key شامل کریں۔

**ریکارڈنگ کیسے شروع کریں؟**  
**Ctrl+Space** (Windows/Linux) یا **Alt+Shift+Q** (Mac) دبائیں اور رکھیں، بولیں، پھر چھوڑیں۔ متن 3 سیکنڈ سے کم میں فعال فیلڈ میں ظاہر ہوتا ہے۔

**کہاں سائن ان کریں؟**  
Chrome toolbar میں LinguaVox آئیکون پر کلک کریں ← "Google سے سائن ان کریں۔" ایک کلک، کوئی پاس ورڈ نہیں۔

**یہ کن ویب سائٹس پر کام کرتا ہے؟**  
کسی بھی ویب سائٹ پر جس میں ٹیکسٹ فیلڈ ہو: Gmail، Slack، Notion، Jira، Salesforce، WhatsApp Web، Telegram Web، LinkedIn اور مزید۔

**یہ کتنا درست ہے؟**  
OpenAI Whisper کی بدولت لفظ کی سطح پر 95%+ درستگی۔ AI improvement modes باقی ماندہ غلطیاں خودبخود درست کر سکتے ہیں۔

**کیا میں ایک زبان میں بول سکتا ہوں اور دوسری میں نتیجہ پا سکتا ہوں؟**  
ہاں۔ Mode کو **ترجمہ** پر سیٹ کریں، اپنی ہدف زبان منتخب کریں۔ کچھ بھی بولیں — نتیجہ ترجمہ شدہ اور بھیجنے کے لیے تیار آتا ہے۔

## رازداری

**کیا میری آواز محفوظ ہوتی ہے؟**  
نہیں۔ آڈیو ریئل ٹائم میں پروسیس ہوتی ہے اور ٹرانسکرپشن کے فوراً بعد حذف ہو جاتی ہے۔ کوئی آواز کا ریکارڈ نہیں رکھا جاتا۔

**کیا LinguaVox میری سکرین یا براؤزر ہسٹری پڑھتا ہے؟**  
نہیں۔ یہ صرف اس وقت فعال ہوتا ہے جب آپ ہاٹ کی دبائے رکھیں۔ یہ دوسرے ٹیبز یا آپ کی براؤزنگ ہسٹری تک رسائی نہیں کر سکتا۔

## حدود اور قیمت

**مفت پلان میں کیا شامل ہے؟**  
روزانہ 20 درخواستیں۔ آدھی رات کو ری سیٹ ہوتی ہیں۔ کوئی کریڈٹ کارڈ درکار نہیں۔

**لامحدود درخواستیں کیسے ملیں؟**  
Dashboard ← API Key میں اپنی OpenAI API key شامل کریں۔ آپ براہ راست OpenAI کو ادائیگی کریں — عام لاگت ماہانہ $0.50 سے کم۔

**تنظیمی اکاؤنٹ کیا ہے؟**  
ایک مشترکہ پلان جہاں ایک API key پوری ٹیم کو کور کرتی ہے۔ ڈیش بورڈ میں ممبرز کا انتظام کریں اور استعمال کے تجزیات دیکھیں۔

## میٹنگ موڈ

**میٹنگ موڈ کیا ہے؟**  
Google Meet، Zoom، Teams اور کسی بھی براؤزر پر مبنی ویڈیو کال کے لیے ریئل ٹائم ترجمہ شدہ سب ٹائٹلز۔ سب ٹائٹلز اسکرین پر فلوٹنگ اوورلے کے طور پر ظاہر ہوتے ہیں۔

**میٹنگ موڈ کیسے شروع کریں؟**  
Chrome toolbar میں LinguaVox آئیکون پر دائیں کلک کریں ← "میٹنگ موڈ شروع کریں۔" فعال ٹیب پر کام کرتا ہے۔

**کیا میٹنگ موڈ macOS پر کام کرتا ہے؟**  
ہاں، لیکن macOS کو براؤزر کے لیے Screen Recording کی اجازت درکار ہے۔ Chrome پہلی بار استعمال پر یہ مانگے گا۔

## مسائل کا حل

**بولنے کے بعد متن ظاہر نہیں ہوا۔**  
پہلے ٹیکسٹ فیلڈ کے اندر کلک کریں، پھر ہاٹ کی دبائے رکھیں۔ یقینی بنائیں کہ LinguaVox آئیکون ظاہر کرتا ہے کہ آپ سائن ان ہیں۔

**اس سائٹ پر ہاٹ کی کام نہیں کر رہی۔**  
LinguaVox براؤزر لیول ہاٹ کی استعمال کرتا ہے جو صفحہ لیول کیپچر (جیسے Slack) کو bypass کرتی ہے۔ اگر پھر بھی کام نہ کرے تو صفحہ ریفریش کریں۔

**میں نے اپنی روزانہ کی حد پوری کر لی۔**  
آدھی رات تک انتظار کریں (حد روزانہ ری سیٹ ہوتی ہے) یا لامحدود استعمال کے لیے اپنی OpenAI API key شامل کریں۔

**ایکسٹینشن "context invalidated" دکھاتی ہے۔**  
صفحہ ریفریش کریں۔ یہ نیویگیشن کے بعد پیچیدہ سنگل پیج ایپس میں ہو سکتا ہے۔
