# LinguaVox — Inställningsguide

Öppna LinguaVox-popupen genom att klicka på ikonen i Chrome-verktygsfältet.

---

## Talspråk

Språket du kommer att tala. Ställ in på **Auto** för automatisk igenkänning, eller välj ett specifikt språk för bättre noggrannhet med accenter eller dialekter.

---

## Läge

| Läge | Vad det gör |
|------|-----------|
| **Transkribera** | Konverterar ditt tal till text precis som det sades |
| **Översätt** | Konverterar ditt tal till ett annat språk |
| **Förbättra** | Transkriberar och tillämpar automatiskt AI-polering |

---

## Utdataspråk (översättningsläge)

När läget är inställt på **Översätt**, välj det språk du vill ha den slutliga texten på.

Exempel:
- Tala ukrainska → utdata: professionell engelska i Gmail
- Tala spanska → utdata: tyska i Slack
- Tala vilket språk som helst → utdata: ett av 21+ språk

---

## AI-förbättring

Förbättrar automatiskt den transkriberade texten. Välj en stil som passar ditt användningsfall:

| Stil | Bäst för |
|------|---------|
| **Smart polering** | Daglig användning — korrigerar grammatik, bevarar mening |
| **Affärsstil** | E-post, rapporter, professionella meddelanden |
| **Endast grammatik** | Grammatik- och stavningskorrigering, ingen omformulering |
| **Kreativ** | Sociala medieinlägg, berättande, kreativt skrivande |
| **Informell** | Chattmeddelanden, informellt samtal |
| **Akademisk** | Uppsatser, forskning, formella dokument |

Förbättring kan stängas av — bara Whisper-transkription körs.

---

## Mötesläge

Lägger till realtidsöversatta undertexter i valfritt videosamtal (Google Meet, Zoom, Teams och andra). Starta det genom att högerklicka på LinguaVox-ikonen. Välj undertitelspråk innan start.

---

## Gränssnittsspråk

Ändrar språket för LinguaVox-popupen. Stöder 14 språk. Påverkar inte transkription eller utdata.

---

## Nattläge

Växlar popupen till ett mörkt tema.

---

## Historik

Senaste transkriptioner sparas lokalt i din webbläsare. Ange hur många som ska sparas (10, 25, 50 eller 100). Historiken är privat — lagras bara på din enhet, aldrig på våra servrar.

---

## API-nyckel

Som standard använder LinguaVox en delad nyckelbassäng (20 förfrågningar/dag gratis). Lägg till din egen OpenAI API-nyckel för obegränsade förfrågningar. Din nyckel lagras säkert i webbläsaren och används bara för dina transkriptioner.

För att lägga till din nyckel: öppna [Instrumentpanel → API Key](https://linguavox.uk/login)
