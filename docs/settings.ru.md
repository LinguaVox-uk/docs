# LinguaVox — Настройки

Откройте всплывающее окно LinguaVox, нажав на иконку на панели Chrome.

---

## Язык речи

Язык, на котором вы будете говорить. Установите **Авто** для автоматического определения или выберите конкретный язык для лучшей точности с акцентами или диалектами.

---

## Режим

| Режим | Что делает |
|-------|-----------|
| **Транскрибировать** | Преобразует вашу речь в текст точно так, как сказано |
| **Перевести** | Преобразует вашу речь на другой язык |
| **Улучшить** | Транскрибирует и автоматически применяет AI-полировку |

---

## Язык вывода (режим перевода)

Когда режим установлен на **Перевести**, выберите язык, на котором хотите получить итоговый текст.

Примеры:
- Говорите по-украински → вывод: профессиональный английский в Gmail
- Говорите по-испански → вывод: немецкий в Slack
- Говорите на любом языке → вывод: любой из 21+ языков

---

## AI-улучшение

Автоматически улучшает транскрибированный текст. Выберите стиль, подходящий для вашего случая:

| Стиль | Лучше всего для |
|-------|----------------|
| **Умная полировка** | Повседневное использование — исправляет грамматику, сохраняет смысл |
| **Деловой стиль** | Письма, отчёты, профессиональные сообщения |
| **Только грамматика** | Исправление грамматики и орфографии, без перефразирования |
| **Творческий** | Посты в соцсетях, сторителлинг, творческое письмо |
| **Разговорный** | Чат-сообщения, неформальное общение |
| **Академический** | Эссе, исследования, официальные документы |

Улучшение можно отключить — тогда выполняется только транскрипция Whisper.

---

## Режим встреч

Добавляет субтитры с переводом в реальном времени к любому видеозвонку (Google Meet, Zoom, Teams и другим). Запускайте щелчком правой кнопки по иконке LinguaVox. Перед запуском выберите язык субтитров.

---

## Язык интерфейса

Изменяет язык всплывающего окна LinguaVox. Поддерживается 14 языков. Не влияет на транскрипцию или вывод.

---

## Ночной режим

Переключает всплывающее окно на тёмную тему.

---

## История

Последние транскрипции сохраняются локально в вашем браузере. Установите количество хранимых записей (10, 25, 50 или 100). История приватна — хранится только на вашем устройстве, никогда на наших серверах.

---

## API-ключ

По умолчанию LinguaVox использует общий пул ключей (20 запросов/день бесплатно). Добавьте собственный API-ключ OpenAI для безлимитных запросов. Ваш ключ хранится безопасно в браузере и используется только для ваших транскрипций.

Чтобы добавить ключ: откройте [Панель управления → API Key](https://linguavox.uk/login)
