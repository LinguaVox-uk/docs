# LinguaVox — Mga Madalas na Tanong

## Pagsisimula

**Kailangan ko ba ng OpenAI API key?**  
Hindi. Ang mga libreng gumagamit ay nakakakuha ng 20 kahilingan sa isang araw nang walang anumang configuration. Magdagdag ng sariling key sa dashboard para sa walang limitasyong paggamit.

**Paano ko sisimulan ang pag-record?**  
Hawakan ang **Ctrl+Space** (Windows/Linux) o **Alt+Shift+Q** (Mac), magsalita, at pakawalan. Lalabas ang teksto sa aktibong field sa loob ng 3 segundo.

**Saan ako mag-sign in?**  
I-click ang LinguaVox icon sa Chrome toolbar → "Mag-sign in gamit ang Google." Isang click, walang password.

**Sa anong mga website ito gumagana?**  
Anumang website na may text field: Gmail, Slack, Notion, Jira, Salesforce, WhatsApp Web, Telegram Web, LinkedIn at iba pa.

## Mga Wika at Katumpakan

**Anong mga wika ang sinusuportahan?**  
21+ wika: Ingles, Ukrainiano, Ruso, Tsino, Espanyol, Aleman, Hapon, Pranses, Koreano, Arabiko, Portuges, Italyano, Polish, Dutch, Turko, Swedo, Rumano, Griyego, Filipino, Urdu, Punjabi at iba pa.

**Gaano ito katumpak?**  
95%+ katumpakan sa antas ng salita gamit ang OpenAI Whisper. Ang mga AI improvement mode ay maaaring awtomatikong ayusin ang mga natitirang pagkakamali.

**Maaari ba akong magsalita sa isang wika at makakuha ng resulta sa isa pa?**  
Oo. Itakda ang Mode sa **Isalin**, piliin ang iyong target na wika. Magsalita ng kahit anong bagay — darating ang resulta nang nasalin at handa nang ipadala.

## Privacy

**Nakaimbak ba ang aking boses?**  
Hindi. Ang audio ay pinoproseso nang real-time at tinatanggal agad pagkatapos ng transcription. Walang voice recording ang nakaimbak.

**Binabasa ba ng LinguaVox ang aking screen o browser history?**  
Hindi. Nag-a-activate lamang ito kapag hinawakan mo ang hotkey. Hindi nito ma-access ang ibang tab o ang iyong kasaysayan ng pagba-browse.

---

## Mga Limitasyon at Presyo

**Ano ang kasama sa libreng plano?**  
20 kahilingan sa isang araw. I-reset sa hatinggabi. Hindi kailangan ng credit card.

**Paano makakakuha ng walang limitasyong kahilingan?**  
Magdagdag ng sariling OpenAI API key sa Dashboard → API Key. Direkta kang magbabayad sa OpenAI — karaniwang gastos ay wala pang $0.50 bawat buwan.

**Ano ang account ng organisasyon?**  
Isang shared plan kung saan ang isang API key ay sumasaklaw sa buong team. Pamahalaan ang mga miyembro at tingnan ang analytics ng paggamit sa dashboard.

---

## Meeting Mode

**Ano ang Meeting Mode?**  
Real-time na isinalin na mga subtitle para sa Google Meet, Zoom, Teams at anumang browser-based na video call. Ang mga subtitle ay lumalabas bilang floating overlay sa screen.

**Paano ko sisimulan ang Meeting Mode?**  
I-right-click ang LinguaVox icon sa Chrome toolbar → "Simulan ang Meeting Mode." Gumagana sa aktibong tab.

**Gumagana ba ang Meeting Mode sa macOS?**  
Oo, ngunit kailangan ng Screen Recording permission para sa browser sa macOS. Hihilingin ito ng Chrome sa unang paggamit.

## Pag-aayos ng Problema

**Hindi lumabas ang teksto pagkatapos kong magsalita.**  
I-click muna ang loob ng text field, pagkatapos hawakan ang hotkey. Siguraduhing ang LinguaVox icon ay nagpapakita na naka-sign in ka.

**Hindi gumagana ang hotkey sa site na ito.**  
Gumagamit ang LinguaVox ng browser-level na hotkey na lumalampas sa page-level na pag-capture (tulad ng Slack). Kung hindi pa rin gumagana, i-refresh ang page.

**Naabot ko na ang aking araw-araw na limitasyon.**  
Hintayin ang hatinggabi (ang limitasyon ay nire-reset araw-araw) o magdagdag ng sariling OpenAI API key para sa walang limitasyong paggamit.

**Nagsasabi ang extension na "context invalidated."**  
I-refresh ang page. Maaaring mangyari ito sa mga kumplikadong single-page application pagkatapos ng navigation.
