# LinguaVox — 設定ガイド

Chrome ツールバーのアイコンをクリックして LinguaVox ポップアップを開きます。

---

## 音声言語

話す言語。**自動**に設定すると LinguaVox が自動検出します。アクセントや方言の精度を上げるには特定の言語を選択してください。

---

## モード

| モード | 機能 |
|--------|------|
| **文字起こし** | 話した通りに音声をテキストに変換 |
| **翻訳** | 音声を別の言語に変換 |
| **拡張** | 文字起こしして自動的に AI ポリッシュを適用 |

---

## 出力言語（翻訳モード）

モードが**翻訳**のとき、最終テキストに使用する言語を選択します。

例：
- ウクライナ語で話す → 出力：Gmail でのプロ英語
- スペイン語で話す → 出力：Slack でのドイツ語
- 任意の言語で話す → 出力：21以上の言語のいずれか

---

## AI 拡張

文字起こしテキストを自動的に改善します。ユースケースに合うスタイルを選択：

| スタイル | 最適な用途 |
|----------|----------|
| **スマートポリッシュ** | 日常使用 — 文法修正、意味を保持 |
| **ビジネススタイル** | メール、レポート、ビジネスメッセージ |
| **文法のみ** | 文法・スペル修正のみ、言い換えなし |
| **クリエイティブ** | SNS投稿、ストーリーテリング、創作 |
| **カジュアル** | チャットメッセージ、カジュアルな会話 |
| **アカデミック** | エッセイ、研究、公式文書 |

拡張はオフにできます — Whisper 文字起こしのみが実行されます。

---

## ミーティングモード

任意のビデオ通話（Google Meet、Zoom、Teams など）にリアルタイム翻訳字幕を追加します。LinguaVox アイコンを右クリックして起動。開始前に字幕言語を選択してください。

---

## インターフェース言語

LinguaVox ポップアップ自体の言語を変更します。14言語をサポート。文字起こしや出力には影響しません。

---

## ナイトモード

ポップアップをダークテーマに切り替えます。

---

## 履歴

最近の文字起こしがブラウザにローカル保存されます。保持する件数を設定（10、25、50、または100）。履歴はプライベート — デバイスのみに保存、サーバーには決して送られません。

---

## API キー

デフォルトでは LinguaVox は共有キープール（1日20リクエスト無料）を使用します。無制限リクエストには独自の OpenAI API キーを追加してください。キーはブラウザに安全に保存され、あなたの文字起こしにのみ使用されます。

キーを追加するには：[ダッシュボード → API Key](https://linguavox.uk/login) を開く
