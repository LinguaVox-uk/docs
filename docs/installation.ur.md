# LinguaVox انسٹال کرنا

## آپشن A — Chrome Web Store (تجویز کردہ)

1. [Chrome Web Store ←](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea) کھولیں
2. **Chrome میں شامل کریں** پر کلک کریں
3. Chrome toolbar میں LinguaVox آئیکون پر کلک کریں
4. **Google سے سائن ان کریں** پر کلک کریں
5. کسی بھی ویب سائٹ پر ٹیکسٹ فیلڈ میں کلک کریں، **Ctrl+Space** دبائے رکھیں اور بولیں ✓

## آپشن B — دستی انسٹالیشن (ZIP)

1. [GitHub Releases ←](https://github.com/kos-4862/linguavox-public/releases/latest) سے `linguavox-3.0.0.zip` ڈاؤن لوڈ کریں
2. اپنے کمپیوٹر پر ایک فولڈر میں انزپ کریں
3. Chrome کھولیں ← `chrome://extensions` پر جائیں
4. **Developer mode** فعال کریں (اوپر دائیں طرف ٹوگل)
5. **Load unpacked** پر کلک کریں ← انزپ شدہ فولڈر منتخب کریں

## پہلا استعمال

انسٹال کرنے کے بعد:
- LinguaVox آئیکون پر کلک کریں ← Google سے سائن ان کریں (ایک کلک، کوئی پاس ورڈ نہیں)
- کسی بھی ویب سائٹ پر ٹیکسٹ فیلڈ میں کلک کریں
- **Ctrl+Space** (Windows/Linux) یا **Alt+Shift+Q** (Mac) دبائے رکھیں اور بولیں
- چھوڑیں — متن 3 سیکنڈ سے کم میں ظاہر ہوتا ہے

## ان انسٹال کریں

Chrome toolbar ← LinguaVox آئیکون پر دائیں کلک کریں ← **Chrome سے ہٹائیں**
