# LinguaVox Kurulumu

## Seçenek A — Chrome Web Mağazası (Önerilen)

1. [Chrome Web Mağazası →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea) sayfasını açın
2. **Chrome'a ekle** butonuna tıklayın
3. Chrome araç çubuğundaki LinguaVox simgesine tıklayın
4. **Google ile oturum aç** butonuna tıklayın
5. Herhangi bir web sitesindeki metin alanına tıklayın, **Ctrl+Space** tuşunu basılı tutun ve konuşun ✓

## Seçenek B — Manuel Kurulum (ZIP)

1. [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest) sayfasından `linguavox-3.0.0.zip` dosyasını indirin
2. Bilgisayarınızdaki bir klasöre çıkartın
3. Chrome'u açın → `chrome://extensions` adresine gidin
4. **Geliştirici modunu** etkinleştirin (sağ üst köşedeki geçiş düğmesi)
5. **Paketlenmemiş öğe yükle** butonuna tıklayın → çıkartılan klasörü seçin

## İlk Kullanım

Kurulumdan sonra:
- LinguaVox simgesine tıklayın → Google ile oturum açın (tek tıklama, şifre yok)
- Herhangi bir web sitesindeki metin alanına tıklayın
- **Ctrl+Space** (Windows/Linux) veya **Alt+Shift+Q** (Mac) tuşlarını basılı tutun ve konuşun
- Bırakın — metin 3 saniye içinde görünür

## Kaldırma

Chrome araç çubuğu → LinguaVox simgesine sağ tıklayın → **Chrome'dan kaldır**
