# Εγκατάσταση LinguaVox

## Επιλογή Α — Chrome Web Store (Συνιστάται)

1. Ανοίξτε το [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Κάντε κλικ στο **Προσθήκη στο Chrome**
3. Κάντε κλικ στο εικονίδιο LinguaVox στη γραμμή εργαλείων Chrome
4. Κάντε κλικ στο **Σύνδεση με Google**
5. Κάντε κλικ σε οποιοδήποτε πεδίο κειμένου, κρατήστε πατημένο **Ctrl+Space** και μιλήστε ✓

## Επιλογή Β — Χειροκίνητη εγκατάσταση (ZIP)

1. Κατεβάστε το `linguavox-3.0.0.zip` από το [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Αποσυμπιέστε σε φάκελο στον υπολογιστή σας
3. Ανοίξτε Chrome → πηγαίνετε στο `chrome://extensions`
4. Ενεργοποιήστε τη **Λειτουργία προγραμματιστή** (εναλλαγή επάνω δεξιά)
5. Κάντε κλικ στο **Φόρτωση αποσυμπιεσμένης επέκτασης** → επιλέξτε τον αποσυμπιεσμένο φάκελο

## Πρώτη χρήση

Μετά την εγκατάσταση:
- Κάντε κλικ στο εικονίδιο LinguaVox → συνδεθείτε με Google (ένα κλικ, χωρίς κωδικό)
- Κάντε κλικ σε οποιοδήποτε πεδίο κειμένου
- Κρατήστε πατημένο **Ctrl+Space** (Windows/Linux) ή **Alt+Shift+Q** (Mac) και μιλήστε
- Αφήστε — το κείμενο εμφανίζεται σε λιγότερο από 3 δευτερόλεπτα

## Απεγκατάσταση

Γραμμή εργαλείων Chrome → δεξί κλικ στο εικονίδιο LinguaVox → **Κατάργηση από το Chrome**
