# Installera LinguaVox

## Alternativ A — Chrome Web Store (Rekommenderat)

1. Öppna [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Klicka på **Lägg till i Chrome**
3. Klicka på LinguaVox-ikonen i Chrome-verktygsfältet
4. Klicka på **Logga in med Google**
5. Klicka på ett textfält på en webbplats, håll ned **Ctrl+Space** och tala ✓

## Alternativ B — Manuell installation (ZIP)

1. Ladda ned `linguavox-3.0.0.zip` från [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Packa upp i en mapp på din dator
3. Öppna Chrome → gå till `chrome://extensions`
4. Aktivera **Utvecklarläge** (knapp uppe till höger)
5. Klicka på **Ladda upp okomprimerat tillägg** → välj den uppackade mappen

## Första användning

Efter installation:
- Klicka på LinguaVox-ikonen → logga in med Google (ett klick, inget lösenord)
- Klicka på ett textfält på en webbplats
- Håll ned **Ctrl+Space** (Windows/Linux) eller **Alt+Shift+Q** (Mac) och tala
- Släpp — texten visas inom 3 sekunder

## Avinstallera

Chrome-verktygsfält → högerklicka på LinguaVox-ikonen → **Ta bort från Chrome**
