# Установка LinguaVox

## Вариант A — Chrome Web Store (Рекомендуется)

1. Откройте [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Нажмите **Добавить в Chrome**
3. Нажмите на иконку LinguaVox на панели Chrome
4. Нажмите **Войти через Google**
5. Щёлкните любое текстовое поле на любом сайте, удерживайте **Ctrl+Space** и говорите ✓

## Вариант B — Ручная установка (ZIP)

1. Загрузите `linguavox-3.0.0.zip` из [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Распакуйте в папку на вашем компьютере
3. Откройте Chrome → перейдите на `chrome://extensions`
4. Включите **Режим разработчика** (переключатель в правом верхнем углу)
5. Нажмите **Загрузить распакованное расширение** → выберите распакованную папку

## Первое использование

После установки:
- Нажмите на иконку LinguaVox → войдите через Google (один клик, без пароля)
- Щёлкните любое текстовое поле на любом сайте
- Удерживайте **Ctrl+Space** (Windows/Linux) или **Alt+Shift+Q** (Mac) и говорите
- Отпустите — текст появится менее чем за 3 секунды

## Удаление

Панель Chrome → щёлкните правой кнопкой на иконку LinguaVox → **Удалить из Chrome**
