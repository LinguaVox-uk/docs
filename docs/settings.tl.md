# LinguaVox — Gabay sa Mga Setting

Buksan ang LinguaVox popup sa pamamagitan ng pag-click sa icon sa Chrome toolbar.

---

## Wika ng Pagsasalita

Ang wikang gagamitin mo sa pagsasalita. Itakda sa **Auto** para awtomatikong matukoy ng LinguaVox, o pumili ng partikular na wika para sa mas magandang katumpakan sa mga accent o diyalekto.

---

## Mode

| Mode | Ginagawa |
|------|---------|
| **Mag-transcribe** | Kino-convert ang iyong pagsasalita sa teksto nang eksakto |
| **Isalin** | Kino-convert ang iyong pagsasalita sa ibang wika |
| **Paunlarin** | Nagta-transcribe at awtomatikong nag-a-apply ng AI polishing |

---

## Output na Wika (Translation mode)

Kapag ang Mode ay nakatakda sa **Isalin**, pumili ng wika para sa final na teksto.

Mga Halimbawa:
- Magsalita ng Ukrainiano → output: propesyonal na Ingles sa Gmail
- Magsalita ng Espanyol → output: Aleman sa Slack
- Magsalita ng anumang wika → output: alinman sa 21+ wika

---

## AI Improvement

Awtomatikong nagpapabuti ng transcribed na teksto. Pumili ng istilo na angkop sa iyong gamit:

| Istilo | Pinakamainam para sa |
|--------|---------------------|
| **Smart Polishing** | Pang-araw-araw na paggamit — nag-aayos ng grammar, pinapanatili ang kahulugan |
| **Business Style** | Mga email, ulat, propesyonal na mensahe |
| **Grammar Lamang** | Pag-aayos ng grammar at spelling, walang pagsasalin |
| **Creative** | Mga post sa social media, storytelling, creative writing |
| **Casual** | Mga chat message, impormal na pag-uusap |
| **Academic** | Mga sanaysay, pananaliksik, pormal na dokumento |

Maaaring i-off ang improvement — ang Whisper transcription lamang ang magpapatakbo.

---

## Meeting Mode

Nagdadagdag ng real-time na isinalin na mga subtitle sa anumang video call (Google Meet, Zoom, Teams at iba pa). I-right-click ang LinguaVox icon para simulan. Pumili ng subtitle na wika bago magsimula.

---

## Wika ng Interface

Binabago ang wika ng LinguaVox popup mismo. Sumusuporta sa 14 na wika. Hindi nakakaapekto sa transcription o output.

---

## Night Mode

Nagpapalit ng popup sa dark theme.

---

## Kasaysayan

Ang mga kamakailang transcription ay naka-save nang lokal sa iyong browser. Itakda kung ilan ang itatago (10, 25, 50, o 100). Ang kasaysayan ay pribado — nakaimbak lamang sa iyong device, hindi kailanman sa aming mga server.

---

## API Key

Sa default, gumagamit ang LinguaVox ng shared key pool (20 kahilingan/araw nang libre). Magdagdag ng sariling OpenAI API key para sa walang limitasyong kahilingan. Ang iyong key ay ligtas na nakaimbak sa browser at ginagamit lamang para sa iyong mga transcription.

Para magdagdag ng iyong key: buksan ang [Dashboard → API Key](https://linguavox.uk/login)
