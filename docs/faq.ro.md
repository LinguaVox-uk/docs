# LinguaVox — Întrebări frecvente

## Primii pași

**Am nevoie de o cheie API OpenAI?**  
Nu. Utilizatorii gratuiți primesc 20 de cereri pe zi fără nicio configurare. Adaugă propria cheie în panoul de control pentru utilizare nelimitată.

**Cum pornesc înregistrarea?**  
Ține apăsat **Ctrl+Spațiu** (Windows/Linux) sau **Alt+Shift+Q** (Mac), vorbește, apoi eliberează. Textul apare în câmpul activ în mai puțin de 3 secunde.

**Unde mă autentific?**  
Fă clic pe pictograma LinguaVox din bara Chrome → "Conectare cu Google." Un clic, fără parolă.

**Pe ce site-uri funcționează?**  
Orice site web cu un câmp de text: Gmail, Slack, Notion, Jira, Salesforce, WhatsApp Web, Telegram Web, LinkedIn și altele.

---

## Limbi și precizie

**Ce limbi sunt suportate?**  
21+ limbi: engleză, ucraineană, rusă, chineză, spaniolă, germană, japoneză, franceză, coreeană, arabă, portugheză, italiană, poloneză, olandeză, turcă, suedeză, română, greacă, filipineză, urdu, punjabi și altele.

**Cât de precisă este?**  
Precizie de 95%+ la nivel de cuvânt cu OpenAI Whisper. Modurile de îmbunătățire AI pot corecta automat erorile rămase.

**Pot vorbi într-o limbă și primi rezultatul în alta?**  
Da. Setează modul pe **Traducere**, alege limba dorită. Vorbește orice — rezultatul vine tradus și gata de trimis.

---

## Confidențialitate

**Vocea mea este stocată?**  
Nu. Sunetul este procesat în timp real și șters imediat după transcriere. Nu sunt păstrate înregistrări vocale.

**LinguaVox îmi citește ecranul sau istoricul browserului?**  
Nu. Se activează doar când ții apăsată tasta de scurtătură. Nu poate accesa alte file sau istoricul de navigare.

---

## Limite și prețuri

**Ce include planul gratuit?**  
20 de cereri pe zi. Se resetează la miezul nopții. Nu este necesară cartea de credit.

**Cum obțin cereri nelimitate?**  
Adaugă propria cheie API OpenAI în Panou → API Key. Plătești direct la OpenAI — costul tipic este sub $0,50 pe lună.

**Ce este un cont de organizație?**  
Un plan partajat unde o cheie API acoperă întreaga echipă. Gestionează membrii și vizualizează analize de utilizare în panou.

---

## Modul ședință

**Ce este modul ședință?**  
Subtitrări traduse în timp real pentru Google Meet, Zoom, Teams și orice apel video din browser. Subtitrările apar ca un overlay flotant pe ecran.

**Cum pornesc modul ședință?**  
Clic dreapta pe pictograma LinguaVox din bara Chrome → "Pornește modul ședință." Funcționează pe fila activă.

**Funcționează modul ședință pe macOS?**  
Da, dar macOS necesită permisiunea de înregistrare a ecranului pentru browser. Chrome va cere acest lucru la prima utilizare.

---

## Depanare

**Textul nu a apărut după ce am vorbit.**  
Mai întâi fă clic în câmpul de text, apoi ține apăsată tasta de scurtătură. Asigură-te că pictograma LinguaVox arată că ești autentificat.

**Tasta de scurtătură nu funcționează pe acest site.**  
LinguaVox folosește o tastă de scurtătură la nivel de browser care ocolește capturile la nivel de pagină (cum ar fi Slack). Dacă tot nu funcționează, reîncarcă pagina.

**Am atins limita zilnică.**  
Așteaptă până la miezul nopții (limita se resetează zilnic) sau adaugă propria cheie API OpenAI pentru utilizare nelimitată.

**Extensia afișează "context invalidated."**  
Reîncarcă pagina. Acest lucru se poate întâmpla în aplicații complexe cu o singură pagină după navigare.
