# LinguaVox — よくある質問

## はじめに

**OpenAI APIキーは必要ですか？**  
いいえ。無料ユーザーは設定なしで1日20リクエストを利用できます。無制限に使用するにはダッシュボードで独自のキーを追加してください。

**録音を開始するには？**  
**Ctrl+Space**（Windows/Linux）または **Alt+Shift+Q**（Mac）を押しながら話し、離してください。テキストは3秒以内にアクティブなフィールドに表示されます。

**どこでサインインしますか？**  
Chromeツールバーの LinguaVox アイコン →「Google でサインイン」をクリック。ワンクリック、パスワード不要。

**どのウェブサイトで動作しますか？**  
テキストフィールドのある任意のウェブサイト：Gmail、Slack、Notion、Jira、Salesforce、WhatsApp Web、Telegram Web、LinkedIn など。

---

## 言語と精度

**サポートされている言語は？**  
21以上の言語：英語、ウクライナ語、ロシア語、中国語、スペイン語、ドイツ語、日本語、フランス語、韓国語、アラビア語、ポルトガル語、イタリア語、ポーランド語、オランダ語、トルコ語、スウェーデン語、ルーマニア語、ギリシャ語、フィリピン語、ウルドゥー語、パンジャブ語など。

**精度はどれくらいですか？**  
OpenAI Whisper により、単語レベルで95%以上の精度。AI 拡張モードが残りのエラーを自動修正できます。

**一つの言語で話して別の言語で出力できますか？**  
はい。モードを**翻訳**に設定し、ターゲット言語を選択。何を話しても、翻訳されて送信準備完了の状態で届きます。

---

## プライバシー

**声は保存されますか？**  
いいえ。音声はリアルタイムで処理され、文字起こし後すぐに削除されます。音声録音は一切保存されません。

**LinguaVox は画面やブラウザ履歴を読み取りますか？**  
いいえ。ホットキーを押しているときのみ起動します。他のタブや閲覧履歴にはアクセスできません。

---

## 制限と料金

**無料プランには何が含まれますか？**  
1日20リクエスト。深夜にリセット。クレジットカード不要。

**無制限リクエストを取得するには？**  
ダッシュボード → API Key で独自の OpenAI APIキーを追加。OpenAI に直接支払い — 典型的なコストは月額$0.50未満。

**組織アカウントとは？**  
1つの API キーでチーム全体をカバーする共有プラン。ダッシュボードでメンバーを管理し、使用状況を分析できます。

---

## ミーティングモード

**ミーティングモードとは？**  
Google Meet、Zoom、Teams、およびブラウザベースのビデオ通話向けのリアルタイム翻訳字幕。字幕は画面上にフローティングオーバーレイとして表示されます。

**ミーティングモードを開始するには？**  
Chrome ツールバーの LinguaVox アイコンを右クリック → 「ミーティングモードを開始」。アクティブなタブで動作します。

**ミーティングモードは macOS で動作しますか？**  
はい。ただし macOS ではブラウザに画面録画の許可が必要です。Chrome が初回使用時に確認します。

---

## トラブルシューティング

**話した後テキストが表示されませんでした。**  
まずテキストフィールド内をクリックし、それからホットキーを押してください。LinguaVox アイコンがサインイン済みを示していることを確認してください。

**このサイトでホットキーが動作しません。**  
LinguaVox はブラウザレベルのホットキーを使用しており、ページレベルのキャプチャ（Slack など）を回避します。それでも動作しない場合はページを更新してください。

**1日の制限に達しました。**  
深夜まで待つ（制限は毎日リセット）か、独自の OpenAI API キーを追加して無制限に使用してください。

**拡張機能が "context invalidated" と表示されます。**  
ページを更新してください。複雑なシングルページアプリでナビゲーション後に発生することがあります。
