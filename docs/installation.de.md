# LinguaVox installieren

## Option A — Chrome Web Store (Empfohlen)

1. Öffne den [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Klicke auf **Zu Chrome hinzufügen**
3. Klicke auf das LinguaVox-Symbol in der Chrome-Symbolleiste
4. Klicke auf **Mit Google anmelden**
5. Klicke in ein beliebiges Textfeld auf einer beliebigen Website, halte **Ctrl+Space** gedrückt und sprich ✓

## Option B — Manuelle Installation (ZIP)

1. Lade `linguavox-3.0.0.zip` von [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest) herunter
2. Entpacke in einen Ordner auf deinem Computer
3. Öffne Chrome → gehe zu `chrome://extensions`
4. Aktiviere den **Entwicklermodus** (Schalter oben rechts)
5. Klicke auf **Entpackte Erweiterung laden** → wähle den entpackten Ordner

## Erste Verwendung

Nach der Installation:
- Klicke auf das LinguaVox-Symbol → mit Google anmelden (ein Klick, kein Passwort)
- Klicke in ein beliebiges Textfeld auf einer beliebigen Website
- Halte **Ctrl+Space** (Windows/Linux) oder **Alt+Shift+Q** (Mac) gedrückt und sprich
- Loslassen — Text erscheint in unter 3 Sekunden

## Deinstallation

Chrome-Symbolleiste → Rechtsklick auf das LinguaVox-Symbol → **Aus Chrome entfernen**
