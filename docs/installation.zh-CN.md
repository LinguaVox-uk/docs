# 安装 LinguaVox

## 方式 A — Chrome 网上应用店（推荐）

1. 打开 [Chrome 网上应用店 →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. 点击**添加至 Chrome**
3. 点击 Chrome 工具栏中的 LinguaVox 图标
4. 点击**使用 Google 登录**
5. 点击任意网站上的文本框，按住 **Ctrl+Space**，然后说话 ✓

## 方式 B — 手动安装（ZIP）

1. 从 [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest) 下载 `linguavox-3.0.0.zip`
2. 解压到计算机上的文件夹
3. 打开 Chrome → 转到 `chrome://extensions`
4. 启用**开发者模式**（右上角的开关）
5. 点击**加载已解压的扩展程序** → 选择解压后的文件夹

## 首次使用

安装后：
- 点击 LinguaVox 图标 → 使用 Google 登录（一键，无需密码）
- 点击任意网站上的文本输入框
- 按住 **Ctrl+Space**（Windows/Linux）或 **Alt+Shift+Q**（Mac）并说话
- 松开——文字在 3 秒内出现

## 卸载

Chrome 工具栏 → 右键点击 LinguaVox 图标 → **从 Chrome 中删除**
