# LinguaVox — Frequently Asked Questions

## Getting Started

**Do I need an OpenAI API key?**  
No. Free users get 20 requests per day with no setup required. Add your own key in the dashboard for unlimited use.

**How do I start recording?**  
Hold **Ctrl+Space** (Windows/Linux) or **Alt+Shift+Q** (Mac), speak, then release. Text appears in the active field in under 3 seconds.

**Where do I sign in?**  
Click the LinguaVox icon in the Chrome toolbar → "Sign in with Google." One click, no password.

**Which websites does it work on?**  
Any website with a text field: Gmail, Slack, Notion, Jira, Salesforce, WhatsApp Web, Telegram Web, LinkedIn, and more.

## Languages & Accuracy

**Which languages are supported?**  
21+ languages: English, Ukrainian, Russian, Chinese, Spanish, German, Japanese, French, Korean, Arabic, Portuguese, Italian, Polish, Dutch, Turkish, Swedish, Romanian, Greek, Filipino, Urdu, Punjabi, and more.

**How accurate is it?**  
95%+ word accuracy using OpenAI Whisper. AI Enhancement modes can fix remaining errors automatically.

**Can I speak in one language and get output in another?**  
Yes. Set Mode to **Translate**, choose your target language. Speak anything — output arrives translated and ready to send.

## Privacy

**Is my voice stored?**  
No. Audio is processed in real time and deleted immediately after transcription. Zero voice recordings are ever stored.

**Does LinguaVox read my screen or browser history?**  
No. It only activates when you hold the hotkey. It cannot access other tabs or your browsing history.

## Limits & Pricing

**What does the free tier include?**  
20 requests per day. Resets at midnight. No credit card required.

**How do I get unlimited requests?**  
Add your own OpenAI API key in Dashboard → API Key. You pay OpenAI directly — typical cost is under $0.50/month for everyday use.

**What is an organization account?**  
A shared plan where one API key covers your whole team. Manage members and view usage analytics in the dashboard.

## Meeting Mode

**What is Meeting Mode?**  
Real-time translated subtitles for Google Meet, Zoom, Teams, and any browser-based video call. Subtitles appear as a floating overlay on the screen.

**How do I start Meeting Mode?**  
Right-click the LinguaVox icon in the Chrome toolbar → "Start Meeting Mode." Works on the active tab.

**Does Meeting Mode work on macOS?**  
Yes, but macOS requires Screen Recording permission for the browser. Chrome will prompt you on first use.

## Troubleshooting

**Text didn't appear after I spoke.**  
Click inside the text field first, then hold the hotkey. Make sure the LinguaVox icon shows you are signed in.

**The hotkey doesn't work on this site.**  
LinguaVox uses a browser-level hotkey that bypasses page-level captures (such as Slack). If it still doesn't work, refresh the page.

**I hit my daily limit.**  
Wait until midnight (limit resets daily) or add your own OpenAI API key for unlimited use.

**The extension says "context invalidated."**  
Refresh the page. This can happen on complex single-page apps after navigation.
