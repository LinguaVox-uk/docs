# Installazione di LinguaVox

## Opzione A — Chrome Web Store (Consigliato)

1. Apri il [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Fai clic su **Aggiungi a Chrome**
3. Fai clic sull'icona LinguaVox nella barra di Chrome
4. Fai clic su **Accedi con Google**
5. Fai clic in un campo di testo su qualsiasi sito, tieni premuto **Ctrl+Space** e parla ✓

## Opzione B — Installazione manuale (ZIP)

1. Scarica `linguavox-3.0.0.zip` da [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Estrai in una cartella sul tuo computer
3. Apri Chrome → vai su `chrome://extensions`
4. Attiva la **Modalità sviluppatore** (interruttore in alto a destra)
5. Fai clic su **Carica estensione non pacchettizzata** → seleziona la cartella estratta

## Primo utilizzo

Dopo l'installazione:
- Fai clic sull'icona LinguaVox → accedi con Google (un clic, nessuna password)
- Fai clic in un campo di testo su qualsiasi sito
- Tieni premuto **Ctrl+Space** (Windows/Linux) o **Alt+Shift+Q** (Mac) e parla
- Rilascia — il testo appare in meno di 3 secondi

## Disinstallazione

Barra di Chrome → clic destro sull'icona LinguaVox → **Rimuovi da Chrome**
