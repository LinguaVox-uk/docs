# LinguaVox — ترتیبات کی رہنمائی

Chrome toolbar میں آئیکون پر کلک کر کے LinguaVox پاپ اپ کھولیں۔

---

## بولنے کی زبان

وہ زبان جس میں آپ بولیں گے۔ خودکار پتہ لگانے کے لیے **خودکار** سیٹ کریں، یا لہجوں یا بولیوں کے ساتھ بہتر درستگی کے لیے مخصوص زبان منتخب کریں۔

---

## موڈ

| موڈ | کیا کرتا ہے |
|-----|-----------|
| **ٹرانسکرائب** | آپ کی گفتگو کو بالکل ویسے ہی متن میں تبدیل کرتا ہے |
| **ترجمہ** | آپ کی گفتگو کو دوسری زبان میں تبدیل کرتا ہے |
| **بہتر بنائیں** | ٹرانسکرائب کرتا ہے اور خودبخود AI پالشنگ لگاتا ہے |

---

## آؤٹ پٹ زبان (ترجمہ موڈ)

جب موڈ **ترجمہ** پر سیٹ ہو، حتمی متن کے لیے مطلوبہ زبان منتخب کریں۔

مثالیں:
- یوکرینی میں بولیں ← آؤٹ پٹ: Gmail میں پیشہ ورانہ انگریزی
- ہسپانوی میں بولیں ← آؤٹ پٹ: Slack میں جرمن
- کسی بھی زبان میں بولیں ← آؤٹ پٹ: 21+ زبانوں میں سے کوئی بھی

---

## AI بہتری

ٹرانسکرائب شدہ متن کو خودبخود بہتر بناتا ہے۔ اپنے استعمال کے لیے موزوں انداز منتخب کریں:

| انداز | بہترین استعمال |
|-------|--------------|
| **ذہین پالش** | روزمرہ استعمال — گرامر درست کرتا ہے، معنی محفوظ رکھتا ہے |
| **کاروباری انداز** | ای میلز، رپورٹس، پیشہ ورانہ پیغامات |
| **صرف گرامر** | گرامر اور اسپیلنگ درستگی، دوبارہ لکھنا نہیں |
| **تخلیقی** | سوشل میڈیا پوسٹس، کہانی سنانا، تخلیقی تحریر |
| **غیررسمی** | چیٹ پیغامات، غیررسمی گفتگو |
| **تعلیمی** | مضامین، تحقیق، رسمی دستاویزات |

بہتری بند کی جا سکتی ہے — صرف Whisper ٹرانسکرپشن چلے گی۔

## میٹنگ موڈ

کسی بھی ویڈیو کال (Google Meet، Zoom، Teams وغیرہ) میں ریئل ٹائم ترجمہ شدہ سب ٹائٹلز شامل کرتا ہے۔ LinguaVox آئیکون پر دائیں کلک کر کے شروع کریں۔ شروع کرنے سے پہلے سب ٹائٹل زبان منتخب کریں۔

## تاریخ

حالیہ ٹرانسکرپشنز آپ کے براؤزر میں مقامی طور پر محفوظ ہوتی ہیں۔ کتنی رکھنی ہیں یہ سیٹ کریں (10، 25، 50 یا 100)۔ تاریخ نجی ہے — صرف آپ کے آلے پر محفوظ، کبھی ہمارے سرورز پر نہیں۔

## API کی

ڈیفالٹ طور پر LinguaVox مشترکہ key pool استعمال کرتا ہے (روزانہ 20 درخواستیں مفت)۔ لامحدود درخواستوں کے لیے اپنی OpenAI API key شامل کریں۔ آپ کی key براؤزر میں محفوظ طریقے سے رکھی جاتی ہے اور صرف آپ کی ٹرانسکرپشنز کے لیے استعمال ہوتی ہے۔

اپنی key شامل کرنے کے لیے: [Dashboard ← API Key](https://linguavox.uk/login) کھولیں
