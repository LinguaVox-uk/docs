# LinguaVox — Foire Aux Questions

## Premiers pas

**Ai-je besoin d'une clé API OpenAI ?**  
Non. Les utilisateurs gratuits reçoivent 20 requêtes par jour sans aucune configuration. Ajoutez votre propre clé dans le tableau de bord pour une utilisation illimitée.

**Comment démarrer l'enregistrement ?**  
Maintenez **Ctrl+Space** (Windows/Linux) ou **Alt+Shift+Q** (Mac), parlez, puis relâchez. Le texte apparaît dans le champ actif en moins de 3 secondes.

**Où me connecter ?**  
Cliquez sur l'icône LinguaVox dans la barre Chrome → "Se connecter avec Google." Un clic, sans mot de passe.

**Sur quels sites web ça fonctionne ?**  
Tout site web avec un champ de texte : Gmail, Slack, Notion, Jira, Salesforce, WhatsApp Web, Telegram Web, LinkedIn et plus encore.

---

## Langues et précision

**Quelles langues sont supportées ?**  
21+ langues : anglais, ukrainien, russe, chinois, espagnol, allemand, japonais, français, coréen, arabe, portugais, italien, polonais, néerlandais, turc, suédois, roumain, grec, filipino, ourdou, pendjabi et plus.

**Quelle est la précision ?**  
95%+ de précision au niveau des mots avec OpenAI Whisper. Les modes d'amélioration IA peuvent corriger automatiquement les erreurs restantes.

**Puis-je parler dans une langue et obtenir le résultat dans une autre ?**  
Oui. Réglez le mode sur **Traduire**, choisissez votre langue cible. Parlez de n'importe quoi — le résultat arrive traduit et prêt à envoyer.

---

## Confidentialité

**Ma voix est-elle stockée ?**  
Non. L'audio est traité en temps réel et supprimé immédiatement après la transcription. Aucun enregistrement vocal n'est conservé.

**LinguaVox lit-il mon écran ou mon historique de navigation ?**  
Non. Il s'active uniquement quand vous maintenez le raccourci. Il ne peut pas accéder aux autres onglets ni à votre historique de navigation.

---

## Limites et tarification

**Que comprend l'offre gratuite ?**  
20 requêtes par jour. Réinitialisé à minuit. Aucune carte de crédit requise.

**Comment obtenir des requêtes illimitées ?**  
Ajoutez votre propre clé API OpenAI dans Tableau de bord → API Key. Vous payez OpenAI directement — coût typique inférieur à $0.50 par mois.

**Qu'est-ce qu'un compte organisation ?**  
Un plan partagé où une clé API couvre toute votre équipe. Gérez les membres et consultez les analyses d'utilisation dans le tableau de bord.

---

## Mode réunion

**Qu'est-ce que le mode réunion ?**  
Sous-titres traduits en temps réel pour Google Meet, Zoom, Teams et tout appel vidéo basé sur navigateur. Les sous-titres apparaissent comme un overlay flottant à l'écran.

**Comment démarrer le mode réunion ?**  
Clic droit sur l'icône LinguaVox dans la barre Chrome → "Démarrer le mode réunion." Fonctionne sur l'onglet actif.

**Le mode réunion fonctionne-t-il sur macOS ?**  
Oui, mais macOS nécessite l'autorisation d'enregistrement d'écran pour le navigateur. Chrome vous le demandera lors de la première utilisation.

---

## Dépannage

**Le texte n'est pas apparu après que j'ai parlé.**  
Cliquez d'abord dans le champ de texte, puis maintenez le raccourci. Assurez-vous que l'icône LinguaVox indique que vous êtes connecté.

**Le raccourci ne fonctionne pas sur ce site.**  
LinguaVox utilise un raccourci au niveau du navigateur qui contourne les captures au niveau de la page (comme Slack). Si ça ne fonctionne toujours pas, actualisez la page.

**J'ai atteint ma limite quotidienne.**  
Attendez jusqu'à minuit (la limite se réinitialise quotidiennement) ou ajoutez votre propre clé API OpenAI pour une utilisation illimitée.

**L'extension indique "context invalidated."**  
Actualisez la page. Cela peut arriver dans des applications monopage complexes après la navigation.
