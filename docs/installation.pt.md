# Instalando o LinguaVox

## Opção A — Chrome Web Store (Recomendado)

1. Abra a [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Clique em **Usar no Chrome**
3. Clique no ícone do LinguaVox na barra do Chrome
4. Clique em **Entrar com Google**
5. Clique em qualquer campo de texto em qualquer site, mantenha **Ctrl+Space** pressionado e fale ✓

## Opção B — Instalação manual (ZIP)

1. Baixe `linguavox-3.0.0.zip` de [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Extraia para uma pasta no seu computador
3. Abra o Chrome → vá para `chrome://extensions`
4. Ative o **Modo de desenvolvedor** (alternância no canto superior direito)
5. Clique em **Carregar sem compactação** → selecione a pasta extraída

## Primeiro uso

Após instalar:
- Clique no ícone do LinguaVox → entre com Google (um clique, sem senha)
- Clique em qualquer campo de texto em qualquer site
- Mantenha **Ctrl+Space** (Windows/Linux) ou **Alt+Shift+Q** (Mac) pressionado e fale
- Solte — o texto aparece em menos de 3 segundos

## Desinstalar

Barra do Chrome → clique com o botão direito no ícone do LinguaVox → **Remover do Chrome**
