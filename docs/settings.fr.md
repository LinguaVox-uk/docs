# LinguaVox — Guide des paramètres

Ouvrez le popup LinguaVox en cliquant sur l'icône dans la barre Chrome.

---

## Langue de la parole

La langue dans laquelle vous parlerez. Réglez sur **Auto** pour que LinguaVox la détecte automatiquement, ou choisissez une langue spécifique pour une meilleure précision avec des accents ou des dialectes.

---

## Mode

| Mode | Ce qu'il fait |
|------|-------------|
| **Transcrire** | Convertit votre voix en texte exactement comme dit |
| **Traduire** | Convertit votre voix dans une autre langue |
| **Améliorer** | Transcrit et applique automatiquement le polissage IA |

---

## Langue de sortie (mode traduction)

Quand le mode est sur **Traduire**, choisissez la langue souhaitée pour le texte final.

Exemples :
- Parler ukrainien → sortie : anglais professionnel dans Gmail
- Parler espagnol → sortie : allemand dans Slack
- Parler n'importe quelle langue → sortie : l'une des 21+ langues

---

## Amélioration IA

Améliore automatiquement votre texte transcrit. Choisissez un style adapté à votre cas d'usage :

| Style | Idéal pour |
|-------|-----------|
| **Polissage intelligent** | Usage quotidien — corrige la grammaire, conserve le sens |
| **Style professionnel** | E-mails, rapports, messages professionnels |
| **Grammaire uniquement** | Correction de grammaire et d'orthographe, sans reformulation |
| **Créatif** | Publications sur les réseaux sociaux, narration, écriture créative |
| **Informel** | Messages de chat, conversation informelle |
| **Académique** | Essais, recherche, documents formels |

L'amélioration peut être désactivée — seule la transcription Whisper s'exécutera.

---

## Mode réunion

Ajoute des sous-titres traduits en temps réel à tout appel vidéo (Google Meet, Zoom, Teams et autres). Démarrez-le en faisant un clic droit sur l'icône LinguaVox. Choisissez la langue des sous-titres avant de commencer.

---

## Langue de l'interface

Change la langue du popup LinguaVox. Prend en charge 14 langues. N'affecte pas la transcription ni la sortie.

---

## Mode nuit

Bascule le popup vers un thème sombre.

---

## Historique

Les transcriptions récentes sont sauvegardées localement dans votre navigateur. Définissez combien conserver (10, 25, 50 ou 100). L'historique est privé — stocké uniquement sur votre appareil, jamais sur nos serveurs.

---

## Clé API

Par défaut, LinguaVox utilise un pool de clés partagées (20 requêtes/jour gratuites). Ajoutez votre propre clé API OpenAI pour des requêtes illimitées. Votre clé est stockée en sécurité dans le navigateur et utilisée uniquement pour vos transcriptions.

Pour ajouter votre clé : ouvrez [Tableau de bord → API Key](https://linguavox.uk/login)
