# Instalarea LinguaVox

## Opțiunea A — Chrome Web Store (Recomandat)

1. Deschide [Chrome Web Store →](https://chromewebstore.google.com/detail/linguavox/dpdejiobdhljljfnkmipjblbpcfhbdea)
2. Apasă **Adaugă în Chrome**
3. Apasă pe pictograma LinguaVox din bara Chrome
4. Apasă **Conectare cu Google**
5. Fă clic într-un câmp de text pe orice site, ține apăsat **Ctrl+Spațiu** și vorbește ✓

## Opțiunea B — Instalare manuală (ZIP)

1. Descarcă `linguavox-3.0.0.zip` din [GitHub Releases →](https://github.com/kos-4862/linguavox-public/releases/latest)
2. Dezarhivează într-un folder pe computer
3. Deschide Chrome → mergi la `chrome://extensions`
4. Activează **Modul dezvoltator** (comutator în colțul din dreapta sus)
5. Apasă **Încarcă extensie neambalată** → selectează folderul dezarhivat

## Prima utilizare

După instalare:
- Apasă pe pictograma LinguaVox → conectează-te cu Google (un clic, fără parolă)
- Fă clic într-un câmp de text pe orice site
- Ține apăsat **Ctrl+Spațiu** (Windows/Linux) sau **Alt+Shift+Q** (Mac) și vorbește
- Eliberează — textul apare în mai puțin de 3 secunde

## Dezinstalare

Bara Chrome → clic dreapta pe pictograma LinguaVox → **Elimină din Chrome**
