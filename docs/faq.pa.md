# LinguaVox — ਅਕਸਰ ਪੁੱਛੇ ਜਾਂਦੇ ਸਵਾਲ

## ਸ਼ੁਰੂਆਤ

**ਕੀ ਮੈਨੂੰ OpenAI API key ਦੀ ਲੋੜ ਹੈ?**  
ਨਹੀਂ। ਮੁਫ਼ਤ ਉਪਭੋਗਤਾ ਬਿਨਾਂ ਕਿਸੇ ਸੈੱਟਅੱਪ ਦੇ ਰੋਜ਼ਾਨਾ 20 ਬੇਨਤੀਆਂ ਪ੍ਰਾਪਤ ਕਰਦੇ ਹਨ। ਅਸੀਮਤ ਵਰਤੋਂ ਲਈ ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ ਆਪਣੀ ਕੁੰਜੀ ਜੋੜੋ।

**ਰਿਕਾਰਡਿੰਗ ਕਿਵੇਂ ਸ਼ੁਰੂ ਕਰਾਂ?**  
**Ctrl+Space** (Windows/Linux) ਜਾਂ **Alt+Shift+Q** (Mac) ਦਬਾ ਕੇ ਰੱਖੋ, ਬੋਲੋ, ਫਿਰ ਛੱਡੋ। 3 ਸਕਿੰਟ ਤੋਂ ਘੱਟ ਸਮੇਂ ਵਿੱਚ ਸਰਗਰਮ ਫੀਲਡ ਵਿੱਚ ਟੈਕਸਟ ਦਿਖਾਈ ਦੇਵੇਗਾ।

**ਸਾਈਨ ਇਨ ਕਿੱਥੇ ਕਰਾਂ?**  
Chrome toolbar ਵਿੱਚ LinguaVox ਆਈਕਨ ਤੇ ਕਲਿੱਕ ਕਰੋ → "Google ਨਾਲ ਸਾਈਨ ਇਨ ਕਰੋ।" ਇੱਕ ਕਲਿੱਕ, ਕੋਈ ਪਾਸਵਰਡ ਨਹੀਂ।

**ਇਹ ਕਿਹੜੀਆਂ ਵੈੱਬਸਾਈਟਾਂ ਤੇ ਕੰਮ ਕਰਦਾ ਹੈ?**  
ਕਿਸੇ ਵੀ ਵੈੱਬਸਾਈਟ ਤੇ ਜਿੱਥੇ ਟੈਕਸਟ ਫੀਲਡ ਹੈ: Gmail, Slack, Notion, Jira, Salesforce, WhatsApp Web, Telegram Web, LinkedIn ਅਤੇ ਹੋਰ।

## ਭਾਸ਼ਾਵਾਂ ਅਤੇ ਸ਼ੁੱਧਤਾ

**ਕਿਹੜੀਆਂ ਭਾਸ਼ਾਵਾਂ ਸਮਰਥਿਤ ਹਨ?**  
21+ ਭਾਸ਼ਾਵਾਂ: ਅੰਗਰੇਜ਼ੀ, ਯੂਕਰੇਨੀ, ਰੂਸੀ, ਚੀਨੀ, ਸਪੈਨਿਸ਼, ਜਰਮਨ, ਜਾਪਾਨੀ, ਫ੍ਰੈਂਚ, ਕੋਰੀਆਈ, ਅਰਬੀ, ਪੁਰਤਗਾਲੀ, ਇਟਾਲੀਅਨ, ਪੋਲਿਸ਼, ਡੱਚ, ਤੁਰਕੀ, ਸਵੀਡਿਸ਼, ਰੋਮਾਨੀਅਨ, ਯੂਨਾਨੀ, ਫਿਲੀਪੀਨੋ, ਉਰਦੂ, ਪੰਜਾਬੀ ਅਤੇ ਹੋਰ।

**ਇਹ ਕਿੰਨਾ ਸਹੀ ਹੈ?**  
OpenAI Whisper ਦੀ ਵਰਤੋਂ ਨਾਲ ਸ਼ਬਦ ਪੱਧਰ ਤੇ 95%+ ਸ਼ੁੱਧਤਾ। AI ਸੁਧਾਰ ਮੋਡ ਬਾਕੀ ਗਲਤੀਆਂ ਨੂੰ ਆਪਣੇ ਆਪ ਠੀਕ ਕਰ ਸਕਦੇ ਹਨ।

**ਕੀ ਮੈਂ ਇੱਕ ਭਾਸ਼ਾ ਵਿੱਚ ਬੋਲ ਕੇ ਦੂਜੀ ਵਿੱਚ ਨਤੀਜਾ ਪ੍ਰਾਪਤ ਕਰ ਸਕਦਾ ਹਾਂ?**  
ਹਾਂ। ਮੋਡ ਨੂੰ **ਅਨੁਵਾਦ** ਤੇ ਸੈੱਟ ਕਰੋ, ਆਪਣੀ ਟਾਰਗੇਟ ਭਾਸ਼ਾ ਚੁਣੋ। ਕੁਝ ਵੀ ਬੋਲੋ — ਨਤੀਜਾ ਅਨੁਵਾਦਿਤ ਅਤੇ ਭੇਜਣ ਲਈ ਤਿਆਰ ਆਵੇਗਾ।

## ਗੋਪਨੀਯਤਾ

**ਕੀ ਮੇਰੀ ਆਵਾਜ਼ ਸੁਰੱਖਿਅਤ ਕੀਤੀ ਜਾਂਦੀ ਹੈ?**  
ਨਹੀਂ। ਆਡੀਓ ਰੀਅਲ ਟਾਈਮ ਵਿੱਚ ਪ੍ਰੋਸੈੱਸ ਕੀਤੀ ਜਾਂਦੀ ਹੈ ਅਤੇ ਟ੍ਰਾਂਸਕ੍ਰਿਪਸ਼ਨ ਤੋਂ ਤੁਰੰਤ ਬਾਅਦ ਮਿਟਾ ਦਿੱਤੀ ਜਾਂਦੀ ਹੈ। ਕੋਈ ਵੀ ਆਵਾਜ਼ ਰਿਕਾਰਡਿੰਗ ਸੁਰੱਖਿਅਤ ਨਹੀਂ ਕੀਤੀ ਜਾਂਦੀ।

**ਕੀ LinguaVox ਮੇਰੀ ਸਕਰੀਨ ਜਾਂ ਬ੍ਰਾਊਜ਼ਰ ਇਤਿਹਾਸ ਪੜ੍ਹਦਾ ਹੈ?**  
ਨਹੀਂ। ਇਹ ਕੇਵਲ ਉਦੋਂ ਸਰਗਰਮ ਹੁੰਦਾ ਹੈ ਜਦੋਂ ਤੁਸੀਂ ਹੌਟਕੀ ਦਬਾ ਕੇ ਰੱਖਦੇ ਹੋ। ਇਹ ਦੂਜੇ ਟੈਬਾਂ ਜਾਂ ਤੁਹਾਡੇ ਬ੍ਰਾਊਜ਼ਿੰਗ ਇਤਿਹਾਸ ਤੱਕ ਨਹੀਂ ਪਹੁੰਚ ਸਕਦਾ।

## ਸੀਮਾਵਾਂ ਅਤੇ ਕੀਮਤਾਂ

**ਮੁਫ਼ਤ ਯੋਜਨਾ ਵਿੱਚ ਕੀ ਸ਼ਾਮਲ ਹੈ?**  
ਰੋਜ਼ਾਨਾ 20 ਬੇਨਤੀਆਂ। ਅੱਧੀ ਰਾਤ ਨੂੰ ਰੀਸੈੱਟ ਹੁੰਦੀਆਂ ਹਨ। ਕੋਈ ਕ੍ਰੈਡਿਟ ਕਾਰਡ ਨਹੀਂ ਚਾਹੀਦਾ।

**ਅਸੀਮਤ ਬੇਨਤੀਆਂ ਕਿਵੇਂ ਪ੍ਰਾਪਤ ਕਰਾਂ?**  
Dashboard → API Key ਵਿੱਚ ਆਪਣੀ OpenAI API key ਜੋੜੋ। ਤੁਸੀਂ ਸਿੱਧੇ OpenAI ਨੂੰ ਭੁਗਤਾਨ ਕਰਦੇ ਹੋ — ਆਮ ਖਰਚ ਮਹੀਨੇਵਾਰ $0.50 ਤੋਂ ਘੱਟ।

**ਸੰਗਠਨ ਖਾਤਾ ਕੀ ਹੈ?**  
ਇੱਕ ਸਾਂਝਾ ਯੋਜਨਾ ਜਿੱਥੇ ਇੱਕ API key ਪੂਰੀ ਟੀਮ ਨੂੰ ਕਵਰ ਕਰਦੀ ਹੈ। ਡੈਸ਼ਬੋਰਡ ਵਿੱਚ ਮੈਂਬਰਾਂ ਦਾ ਪ੍ਰਬੰਧਨ ਕਰੋ ਅਤੇ ਵਰਤੋਂ ਵਿਸ਼ਲੇਸ਼ਣ ਦੇਖੋ।

## ਮੀਟਿੰਗ ਮੋਡ

**ਮੀਟਿੰਗ ਮੋਡ ਕੀ ਹੈ?**  
Google Meet, Zoom, Teams ਅਤੇ ਕਿਸੇ ਵੀ ਬ੍ਰਾਊਜ਼ਰ-ਅਧਾਰਿਤ ਵੀਡੀਓ ਕਾਲ ਲਈ ਰੀਅਲ ਟਾਈਮ ਅਨੁਵਾਦਿਤ ਉਪਸਿਰਲੇਖ। ਉਪਸਿਰਲੇਖ ਸਕਰੀਨ ਤੇ ਫਲੋਟਿੰਗ ਓਵਰਲੇ ਵਜੋਂ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ।

**ਮੀਟਿੰਗ ਮੋਡ ਕਿਵੇਂ ਸ਼ੁਰੂ ਕਰਾਂ?**  
Chrome toolbar ਵਿੱਚ LinguaVox ਆਈਕਨ ਤੇ ਸੱਜਾ ਕਲਿੱਕ ਕਰੋ → "ਮੀਟਿੰਗ ਮੋਡ ਸ਼ੁਰੂ ਕਰੋ।" ਸਰਗਰਮ ਟੈਬ ਤੇ ਕੰਮ ਕਰਦਾ ਹੈ।

**ਕੀ ਮੀਟਿੰਗ ਮੋਡ macOS ਤੇ ਕੰਮ ਕਰਦਾ ਹੈ?**  
ਹਾਂ, ਪਰ macOS ਨੂੰ ਬ੍ਰਾਊਜ਼ਰ ਲਈ ਸਕਰੀਨ ਰਿਕਾਰਡਿੰਗ ਦੀ ਇਜਾਜ਼ਤ ਦੀ ਲੋੜ ਹੈ। Chrome ਪਹਿਲੀ ਵਾਰ ਵਰਤੋਂ ਤੇ ਇਹ ਪੁੱਛੇਗਾ।

## ਸਮੱਸਿਆ ਨਿਵਾਰਨ

**ਬੋਲਣ ਤੋਂ ਬਾਅਦ ਟੈਕਸਟ ਨਹੀਂ ਦਿਖਾਈ ਦਿੱਤਾ।**  
ਪਹਿਲਾਂ ਟੈਕਸਟ ਫੀਲਡ ਦੇ ਅੰਦਰ ਕਲਿੱਕ ਕਰੋ, ਫਿਰ ਹੌਟਕੀ ਦਬਾ ਕੇ ਰੱਖੋ। ਯਕੀਨੀ ਕਰੋ ਕਿ LinguaVox ਆਈਕਨ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਸਾਈਨ ਇਨ ਹੋ।

**ਇਸ ਸਾਈਟ ਤੇ ਹੌਟਕੀ ਕੰਮ ਨਹੀਂ ਕਰਦੀ।**  
LinguaVox ਬ੍ਰਾਊਜ਼ਰ-ਪੱਧਰ ਦੀ ਹੌਟਕੀ ਵਰਤਦਾ ਹੈ ਜੋ ਪੇਜ-ਪੱਧਰ ਕੈਪਚਰ (ਜਿਵੇਂ Slack) ਨੂੰ ਬਾਈਪਾਸ ਕਰਦੀ ਹੈ। ਜੇ ਫਿਰ ਵੀ ਕੰਮ ਨਹੀਂ ਕਰਦੀ, ਪੇਜ ਰਿਫਰੈਸ਼ ਕਰੋ।

**ਮੈਂ ਆਪਣੀ ਰੋਜ਼ਾਨਾ ਸੀਮਾ ਪੂਰੀ ਕਰ ਲਈ।**  
ਅੱਧੀ ਰਾਤ ਤੱਕ ਉਡੀਕ ਕਰੋ (ਸੀਮਾ ਰੋਜ਼ਾਨਾ ਰੀਸੈੱਟ ਹੁੰਦੀ ਹੈ) ਜਾਂ ਅਸੀਮਤ ਵਰਤੋਂ ਲਈ ਆਪਣੀ OpenAI API key ਜੋੜੋ।

**ਐਕਸਟੈਂਸ਼ਨ "context invalidated" ਦਿਖਾਉਂਦਾ ਹੈ।**  
ਪੇਜ ਰਿਫਰੈਸ਼ ਕਰੋ। ਇਹ ਨੇਵੀਗੇਸ਼ਨ ਤੋਂ ਬਾਅਦ ਗੁੰਝਲਦਾਰ ਸਿੰਗਲ-ਪੇਜ ਐਪਸ ਵਿੱਚ ਹੋ ਸਕਦਾ ਹੈ।
