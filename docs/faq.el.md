# LinguaVox — Συχνές Ερωτήσεις

## Ξεκινώντας

**Χρειάζομαι κλειδί API από την OpenAI;**  
Όχι. Οι δωρεάν χρήστες λαμβάνουν 20 αιτήματα ημερησίως χωρίς καμία ρύθμιση. Προσθέστε το δικό σας κλειδί στον πίνακα ελέγχου για απεριόριστη χρήση.

**Πώς ξεκινώ την εγγραφή;**  
Κρατήστε πατημένο **Ctrl+Space** (Windows/Linux) ή **Alt+Shift+Q** (Mac), μιλήστε και αφήστε. Το κείμενο εμφανίζεται στο ενεργό πεδίο σε λιγότερο από 3 δευτερόλεπτα.

**Πού συνδέομαι;**  
Κάντε κλικ στο εικονίδιο LinguaVox στη γραμμή εργαλείων του Chrome → "Σύνδεση με Google." Ένα κλικ, χωρίς κωδικό.

**Σε ποιες ιστοσελίδες λειτουργεί;**  
Σε κάθε ιστοσελίδα με πεδίο κειμένου: Gmail, Slack, Notion, Jira, Salesforce, WhatsApp Web, Telegram Web, LinkedIn και άλλα.

**Ποιες γλώσσες υποστηρίζονται;**  
21+ γλώσσες: αγγλικά, ουκρανικά, ρωσικά, κινεζικά, ισπανικά, γερμανικά, ιαπωνικά, γαλλικά, κορεάτικα, αραβικά, πορτογαλικά, ιταλικά, πολωνικά, ολλανδικά, τουρκικά, σουηδικά, ρουμανικά, ελληνικά, φιλιππινέζικα, ουρντού, παντζαμπικά και άλλα.

**Πόσο ακριβές είναι;**  
95%+ ακρίβεια σε επίπεδο λέξης με OpenAI Whisper. Οι λειτουργίες βελτίωσης ΤΝ μπορούν να διορθώσουν αυτόματα τα υπόλοιπα σφάλματα.

**Μπορώ να μιλάω σε μια γλώσσα και να λαμβάνω αποτέλεσμα σε άλλη;**  
Ναι. Ορίστε τη λειτουργία σε **Μετάφραση**, επιλέξτε τη γλώσσα-στόχο. Μιλήστε οτιδήποτε — το αποτέλεσμα φτάνει μεταφρασμένο και έτοιμο για αποστολή.

## Απόρρητο

**Αποθηκεύεται η φωνή μου;**  
Όχι. Ο ήχος επεξεργάζεται σε πραγματικό χρόνο και διαγράφεται αμέσως μετά τη μεταγραφή. Δεν αποθηκεύονται ηχητικές εγγραφές.

**Διαβάζει η LinguaVox την οθόνη μου ή το ιστορικό περιήγησής μου;**  
Όχι. Ενεργοποιείται μόνο όταν κρατάτε πατημένο το πλήκτρο συντόμευσης. Δεν έχει πρόσβαση σε άλλες καρτέλες ή το ιστορικό σας.

## Όρια και τιμολόγηση

**Τι περιλαμβάνει το δωρεάν πλάνο;**  
20 αιτήματα ημερησίως. Επαναφορά τα μεσάνυχτα. Δεν απαιτείται πιστωτική κάρτα.

**Πώς αποκτώ απεριόριστα αιτήματα;**  
Προσθέστε το δικό σας κλειδί API OpenAI στον Πίνακα ελέγχου → API Key. Πληρώνετε απευθείας στην OpenAI — τυπικό κόστος κάτω από $0,50 το μήνα.

**Τι είναι ο εταιρικός λογαριασμός;**  
Κοινόχρηστο πλάνο όπου ένα κλειδί API καλύπτει όλη την ομάδα σας. Διαχειριστείτε μέλη και δείτε αναλυτικά στοιχεία χρήσης στον πίνακα ελέγχου.

## Λειτουργία Σύσκεψης

**Τι είναι η Λειτουργία Σύσκεψης;**  
Μεταφρασμένοι υπότιτλοι σε πραγματικό χρόνο για Google Meet, Zoom, Teams και οποιαδήποτε βιντεοκλήση στο πρόγραμμα περιήγησης. Οι υπότιτλοι εμφανίζονται ως κινούμενο επίστρωμα στην οθόνη.

**Πώς ξεκινώ τη Λειτουργία Σύσκεψης;**  
Δεξί κλικ στο εικονίδιο LinguaVox στη γραμμή εργαλείων Chrome → "Εκκίνηση Λειτουργίας Σύσκεψης." Λειτουργεί στην ενεργή καρτέλα.

**Λειτουργεί η Λειτουργία Σύσκεψης στο macOS;**  
Ναι, αλλά το macOS απαιτεί άδεια εγγραφής οθόνης για τον browser. Το Chrome θα το ζητήσει κατά την πρώτη χρήση.

## Αντιμετώπιση προβλημάτων

**Το κείμενο δεν εμφανίστηκε μετά που μίλησα.**  
Κάντε πρώτα κλικ μέσα στο πεδίο κειμένου, μετά κρατήστε πατημένο το πλήκτρο συντόμευσης. Βεβαιωθείτε ότι το εικονίδιο LinguaVox δείχνει ότι είστε συνδεδεμένοι.

**Το πλήκτρο συντόμευσης δεν λειτουργεί σε αυτόν τον ιστότοπο.**  
Η LinguaVox χρησιμοποιεί πλήκτρο συντόμευσης σε επίπεδο προγράμματος περιήγησης που παρακάμπτει τις λήψεις σε επίπεδο σελίδας (όπως το Slack). Εάν εξακολουθεί να μην λειτουργεί, ανανεώστε τη σελίδα.

**Έφτασα στο ημερήσιο όριό μου.**  
Περιμένετε μέχρι τα μεσάνυχτα (το όριο επαναφέρεται καθημερινά) ή προσθέστε το δικό σας κλειδί API OpenAI για απεριόριστη χρήση.

**Η επέκταση εμφανίζει "context invalidated."**  
Ανανεώστε τη σελίδα. Αυτό μπορεί να συμβεί σε σύνθετες εφαρμογές μίας σελίδας μετά από πλοήγηση.
